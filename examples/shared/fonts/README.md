# Demo font assets

The demo uses unmodified DejaVu Sans 2.37 font files as its explicit licensed
fallback registry:

- `DejaVuSans.ttf`
- `DejaVuSans-Bold.ttf`

Source: https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37

The upstream license and attribution are retained in `DejaVu-LICENSE.txt`.
