# Deferred feature inventory

This inventory prevents generic-tree preservation from being mistaken for semantic support. `preserved` means the canonical tree retains ordered OOXML structurally; it does not imply typed semantics, editing, or Word-fidelity layout. Every lane below remains unsupported by this paragraph slice.

- **Tables:** parse `typed/generic canonical tree`; model `typed w:tbl vocabulary with bounded spans, plus w:tblStyle resolved through its basedOn chain and w:tblLook read from both the modern attributes and the legacy bitmask`; layout `body table rows and cell paragraphs supported, with all twelve w:cnfStyle conditional formats derived in Word's precedence order and an explicit w:cnfStyle replacing the derivation, plus semantic interaction geometry for column dividers, outer-right edges, and hover insertion targets`; edit `cell paragraph text supported, plus structural removal — a range that fully contains a table removes it, and the same op removes a row or a block paragraph; the bounded Word-like slice adds atomic row/column insert and delete, adjacent divider and outer-right column resize, selected-cell borders and fill, and table-aware context-menu commands through TreeDocumentStore — merge/split, row-height resize, autofit, distribute columns, table-properties dialog, and structural edits inside headers, footers, footnotes, or endnotes remain deferred`; save `normalized structural preservation with D9 canonical fingerprint and save/reopen semantic digest gates on table-editing fixtures`; future gate: merge/split and row-height resize, Word comparison fixtures for the deferred operations, and paired adapter acceptance for the full slice. A conditional format contributes cell shading, cell borders, and the `w:pPr`/`w:rPr` its cell paragraphs and runs inherit; conditional `w:tcMar`, `w:trPr`, and `w:tblPr` inside `w:tblStylePr` are read past rather than applied. Only the row-oriented conditions have tests — `firstCol`, `lastCol`, `band1Vert`/`band2Vert`, and the four corner conditions are derived but unproven. The public editor contract names `insertRow`, `insertColumn`, `deleteRow`, `deleteColumn`, `deleteTable`, `setCellFill`, and `setTableBorders` with allowlisted border targets/styles and nullable fill; `mergeCells` and `splitCell` remain declared but refused in this slice. Row removal is in the op vocabulary and tested, but nothing emits it yet: a range only partially covering a table deliberately keeps its structure, so no plan asks for it. Tables with horizontal or vertical merges refuse column insertion, column deletion, and column resizing with a specific reason.
- **Inline and floating drawings/images:** parse `generic preserved with bounded relationships`; model `untyped drawing/media references`; layout `deferred`; edit `deferred`; save `normalized structural preservation with safe relationship targets`; future gate: typed drawing model, embedded-resource validation, inline/floating positioning and wrap, image operations, and paired acceptance.
- **Footnotes and endnotes:** parse `typed footnotes/endnotes/note/noteReference/noteRef/separator vocabulary`; model `typed note identities, derived numbering, note lifecycle ops, notesPart story stores`; layout `note stories with pageBottom/beneathText reservation, sectEnd/docEnd collection, continuation splits, bounded reflow`; edit `React scoped note editing + insert/delete/convert/setNoteProperties chrome; Vue deferred`; save `normalized structural preservation with relationships`; remaining: Vue parity, notes-in-HF layout, tracked note inserts, images in notes, authored continuationNotice UI, dedicated property-matrix fixtures beyond existing word fixtures.
- **Headers and footers:** parse `related story parts with typed section references`; model `per-section header/footer references with titlePage and evenAndOdd inheritance, plus lifecycle create/delete/link/unlink/options`; layout `page furniture laid out per section with titlePage/first-page/even-odd variant selection, including bounded allowlisted PAGE/NUMPAGES/SECTIONPAGES projection (PAGE honours pgNumType start/fmt)`; edit `React scoped HF editing + insert chrome; Vue deferred`; save `normalized structural preservation with relationships`; remaining: Vue twin, dedicated mid-document/tall-header fixture matrix, note references inside HF, watermark/drawing authoring, tracked changes inside furniture, structural table ops inside furniture.
- **Fields and field instructions:** parse `typed fldChar/instrText/fldSimple where schema-legal, otherwise generic preserved inertly`; model `typed page-number complex fields are addressable atoms; non-allowlisted instructions stay non-executable`; layout `furniture-only live projection for exact allowlisted complex PAGE/NUMPAGES/SECTIONPAGES under bounded per-page context; body fields and w:fldSimple page instructions stay layout-inert (cached result text may still show when addressable as runs)`; edit `insert/delete of allowlisted page fields in open React HF scope; general field authoring/evaluation deferred`; save `normalized structural preservation including dirty/fldLock and inert ffData children`; future gate: body layout/edit operations, addressable simple-field evaluation policy, and security tests keeping DDE and external inclusion non-executable.
- **Content controls (SDTs):** parse `typed contentControl/contentControlContent nodes at block, inline, row, and cell level with bounded nesting; unmodelled w:sdtPr children stay generic`; model `typed CT_SdtPr and type payloads, stable identity, nested lock union, placeholder/temporary semantics, and set-content-control-value ops; w:dataBinding and w:placeholder/w:docPart preserved but not resolved`; layout `block content flattens transparently; inline SDT UTF-16 offset accounting; boundary records per control; placeholder distinguished via w:sdtPr/w:rPr`; edit `store-enforced per-control w:lock union, literal placeholder first-input replace (no empty-restore without glossary), w:temporary self-remove, w:dataBinding bound refusal, typed value ops with public setContentControlValue: { value: string }; React authoring surface — widgets, form-fill navigation, inspector, chrome slots; Vue deferred`; save `normalized structural preservation`; remaining: Vue parity, w:dataBinding resolution against custom XML, glossary w:placeholder resolution and restore-from-glossary, repeating-section add/remove (shipped API refuses unsupported), w:documentProtection/w:formProt forms mode, w:customXml/w:smartTag offset parity, Developer-tab insert authoring, full D9/fixture verification and paired acceptance.
- **Tracked changes:** parse `generic preserved`; model `untyped revision wrappers`; layout `deferred`; edit `deferred, including accept/reject`; save `normalized structural preservation`; future gate: typed revisions and provenance, review projection, accept/reject `DocOp`s, layout, save/reopen conformance, and paired acceptance.
- **Comments and annotations:** parse `generic preserved with relationships and anchor markup`; model `untyped anchors and bodies`; layout `deferred`; edit `deferred`; save `normalized structural preservation`; future gate: durable typed anchors, comment operations, presentation, orphan/overlap policy, save/reopen conformance, and paired acceptance.
- **Hyperlinks and external relationships:** parse `generic preserved after safe-target classification`; model `untyped relationship-backed content`; layout `deferred`; edit/activation `deferred with no zero-click fetch`; save `normalized structural preservation of safe relationship data`; future gate: typed hyperlink nodes, sanitized URL commands, explicit user activation, layout, and paired acceptance.
- **Paragraph properties outside the accepted boundary:** parse `generic preserved`; model `untyped or unresolved except the D8-accepted set`; layout `deferred`; edit `deferred`; save `normalized structural preservation`; future gate: an explicit typed property addition, resolver/layout behavior, semantic operation, canonical fingerprint fixture, and paired acceptance. The accepted boundary itself is fixed in `design.md` D8. **All six `w:pBdr` edges** (`top`, `left`, `bottom`, `right`, `between`, `bar`) now resolve from the tree and from the style cascade, reserve flow height where Word reserves it, and paint, so they are no longer deferred as a lane. What remains deferred inside that lane: border **authoring** — `w:pBdr` is not an accepted paragraph property, so no operation adds, changes, or removes a border and the element survives edits only as preserved structure; `w:between` in table-cell and header/footer flow, where grouping has no neighbour lookahead and a cell paragraph declaring only `w:between` publishes no stroke at all; `w:shadow`, which is read and folded into group identity but never drawn; `w:themeColor`/`w:themeTint`/`w:themeShade`, which are not read, so a theme-coloured edge with no literal `w:color` paints black; and every `w:val` outside `single`/`dashed`/`dotted`/`double`, which paints as a solid rule. **`w:contextualSpacing`** resolves in body flow and suppresses the gap between same-style neighbours, but is deliberately not applied to paragraphs inside table cells, where Word does apply it. **`w:beforeAutospacing`/`w:afterAutospacing`** and the character-unit indent spellings (`w:firstLineChars`, `w:hangingChars`, `w:startChars`, `w:endChars`) are not modelled at all; a document authoring them lays out from whatever literal twip values it also states.
- **Themes, styles, and fonts beyond the accepted resolver inputs:** parse `generic preserved`; model `untyped or unresolved dependencies`; layout `deferred`; edit `deferred`; save `normalized structural preservation`; future gate: typed dependency graph, validated font resources, complete cascade rules, Word comparison fixtures, and paired acceptance.
- **Sections, columns, and pagination rules outside the accepted paragraph boundary:** parse `typed section properties from paragraph-level and body w:sectPr, including all five w:type values and equal/unequal w:cols geometry`; model `enumerated body sections with page size, margins, landscape, titlePage, break type, bounded column widths/gaps, and separator intent`; layout `section-aware pagination with per-section geometry/margins, equal and unequal column flow, explicit column breaks, separator records, default/nextPage and continuous breaks, and per-section read-only header/footer furniture`; edit `page size, orientation and margins per section, plus a section-mark insertion that clones the governing w:sectPr — no break-type or column authoring`; save `normalized structural preservation`; future gate: `evenPage`/`oddPage`/`nextColumn` section semantics, column authoring, save/reopen fixtures for unsupported break types, and paired acceptance. `continuous` sections are implemented and no longer deferred: a continuous boundary shares the preceding sheet, continuing the flow cursor and carrying space-after across. It is conservative rather than complete — sharing requires identical geometry and identical furniture, so a continuous boundary that changes only margins still starts a new sheet where Word continues the current one. `evenPage`, `oddPage`, and `nextColumn` parse but paginate exactly like `nextPage`, with no blank page inserted to reach the requested parity, and a test pins that as the deferred behaviour rather than the Word one. Multi-column sections now divide the content box into bounded regions, re-break paragraph continuations for unequal widths, advance natural and explicit breaks through columns before sheets, and participate in the incremental structure key; paired adapter acceptance and column-authoring commands remain deferred. A multi-column section that ends in a continuous section break balances (§17.6.4) when its content occupies a single open sheet: the flow re-runs against the shortest fitting column height, tables split at row boundaries across columns, and the following section resumes below the whole balanced region. Balancing the trailing sheet of a multi-page section and the `w:noColumnBalance` compatibility opt-out remain deferred.
- **Collaboration and replicated undo:** parse `not applicable to DOCX input`; model `replication backend and durable state deferred`; layout `uses only committed local revisions in this slice`; edit `remote operations, awareness, and replicated undo deferred`; save `replicated snapshots/compaction deferred`; future gate: separately specified schema, typed origins, convergence, actor-local undo, durable snapshots, retention/GC, semantic repair, and two-replica conformance.
- **Deterministic PDF, print, and export:** parse `consumes an already accepted canonical model only`; model `no separate authored model allowed`; layout `deterministic shaping and positioned output deferred`; edit `not applicable`; save/export `PDF/print artifacts deferred`; future gate: deterministic font/shaping resources, positioned semantic output contract, backend conformance, and reproducible fixtures independent of browser DOM.
- **Server rendering and language bindings:** parse `headless bounded loading deferred`; model `canonical-tree transport/versioning deferred`; layout `headless layout deferred`; edit `headless commands and language bindings deferred`; save `headless normalized package output deferred`; future gate: browser/headless paragraph parity, resource ports, transport/versioning, server security limits, and language-specific conformance.
- **Public object model, agents, plugins, and MCP expansion:** parse `unchanged existing behavior`; model `new typed-tree facade deferred`; layout `new extension hooks deferred`; edit `new commands deferred`; save `new extension serialization deferred`; future gate: separately specified and versioned public contracts with capability isolation and conformance tests.
