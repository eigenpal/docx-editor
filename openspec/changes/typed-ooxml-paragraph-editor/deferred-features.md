# Deferred feature inventory

This inventory prevents generic-tree preservation from being mistaken for semantic support. `preserved` means the canonical tree retains ordered OOXML structurally; it does not imply typed semantics, editing, or Word-fidelity layout. Every lane below remains unsupported by this paragraph slice.

- **Tables:** parse `typed/generic canonical tree`; model `typed w:tbl vocabulary with bounded spans, plus w:tblStyle resolved through its basedOn chain and w:tblLook read from both the modern attributes and the legacy bitmask`; layout `body table rows and cell paragraphs supported, with all twelve w:cnfStyle conditional formats derived in Word's precedence order and an explicit w:cnfStyle replacing the derivation`; edit `cell paragraph text supported, plus structural removal — a range that fully contains a table removes it, and the same op removes a row or a block paragraph; the remaining structural table operations are deferred`; save `normalized structural preservation`; future gate: the remaining structural table operations, merged-cell interaction, Word comparison fixtures, and paired adapter acceptance. A conditional format contributes cell shading, cell borders, and the `w:pPr`/`w:rPr` its cell paragraphs and runs inherit; conditional `w:tcMar`, `w:trPr`, and `w:tblPr` inside `w:tblStylePr` are read past rather than applied. Only the row-oriented conditions have tests — `firstCol`, `lastCol`, `band1Vert`/`band2Vert`, and the four corner conditions are derived but unproven. The structural operations named in the editor contract (`insertRow`, `insertColumn`, `mergeCells`, `insertTable`, and the rest) exist as type declarations only and are refused with a typed `unsupported` reason rather than silently dropped. Row removal is in the op vocabulary and tested, but nothing emits it yet: a range only partially covering a table deliberately keeps its structure, so no plan asks for it.
- **Inline and floating drawings/images:** parse `generic preserved with bounded relationships`; model `untyped drawing/media references`; layout `deferred`; edit `deferred`; save `normalized structural preservation with safe relationship targets`; future gate: typed drawing model, embedded-resource validation, inline/floating positioning and wrap, image operations, and paired acceptance.
- **Headers and footers:** parse `related story parts with typed section references`; model `per-section header/footer references with titlePage and evenAndOdd inheritance`; layout `read-only page furniture laid out per section with titlePage/first-page variant selection, including bounded allowlisted PAGE/NUMPAGES projection for furniture numbering`; edit `deferred`; save `normalized structural preservation with relationships`; future gate: scoped editing, inherited page-furniture interaction, save/reopen fixtures, and paired acceptance.
- **Footnotes and endnotes:** parse `generic preserved by related story part`; model `untyped note references and bodies`; layout `deferred`; edit `deferred`; save `normalized structural preservation with relationships`; future gate: typed note identities/references, continuation pagination, scoped editing, save/reopen fixtures, and paired acceptance.
- **Fields and field instructions:** parse `generic preserved inertly`; model `untyped and non-executable`; layout `deferred for body fields — generic w:fldSimple cached results are not addressable by tree ops/model ranges and body pagination lacks per-page projection context; read-only page-furniture numbering only projects exact allowlisted complex PAGE/NUMPAGES under a bounded per-page context`; edit `deferred`; save `normalized structural preservation`; future gate: safe typed field taxonomy (including addressable simple fields), result/instruction policy, body layout/edit operations, and security tests keeping DDE and external inclusion non-executable.
- **Content controls (SDTs):** parse `generic preserved with bounded nesting`; model `untyped generic nodes`; layout `deferred`; edit `deferred`; save `normalized structural preservation`; future gate: typed SDT properties/content, lock and nesting semantics, projection/layout behavior, operations, and paired acceptance. Because a block-level `w:sdt` is generic rather than a typed block, a range deletion cannot remove one: it stays as an empty container, and each surviving container is a join boundary, so a whole-document delete leaves one empty paragraph beside it. Paragraphs inside an SDT that layout does not emit are never covered by a selection, which is also why a table holding one is emptied rather than removed.
- **Tracked changes:** parse `generic preserved`; model `untyped revision wrappers`; layout `deferred`; edit `deferred, including accept/reject`; save `normalized structural preservation`; future gate: typed revisions and provenance, review projection, accept/reject `DocOp`s, layout, save/reopen conformance, and paired acceptance.
- **Comments and annotations:** parse `generic preserved with relationships and anchor markup`; model `untyped anchors and bodies`; layout `deferred`; edit `deferred`; save `normalized structural preservation`; future gate: durable typed anchors, comment operations, presentation, orphan/overlap policy, save/reopen conformance, and paired acceptance.
- **Hyperlinks and external relationships:** parse `generic preserved after safe-target classification`; model `untyped relationship-backed content`; layout `deferred`; edit/activation `deferred with no zero-click fetch`; save `normalized structural preservation of safe relationship data`; future gate: typed hyperlink nodes, sanitized URL commands, explicit user activation, layout, and paired acceptance.
- **Paragraph properties outside the accepted boundary:** parse `generic preserved`; model `untyped or unresolved except the D8-accepted set`; layout `deferred`; edit `deferred`; save `normalized structural preservation`; future gate: an explicit typed property addition, resolver/layout behavior, semantic operation, canonical fingerprint fixture, and paired acceptance. The accepted boundary itself is fixed in `design.md` D8. **All six `w:pBdr` edges** (`top`, `left`, `bottom`, `right`, `between`, `bar`) now resolve from the tree and from the style cascade, reserve flow height where Word reserves it, and paint, so they are no longer deferred as a lane. What remains deferred inside that lane: border **authoring** — `w:pBdr` is not an accepted paragraph property, so no operation adds, changes, or removes a border and the element survives edits only as preserved structure; `w:between` in table-cell and header/footer flow, where grouping has no neighbour lookahead and a cell paragraph declaring only `w:between` publishes no stroke at all; `w:shadow`, which is read and folded into group identity but never drawn; `w:themeColor`/`w:themeTint`/`w:themeShade`, which are not read, so a theme-coloured edge with no literal `w:color` paints black; and every `w:val` outside `single`/`dashed`/`dotted`/`double`, which paints as a solid rule. **`w:contextualSpacing`** resolves in body flow and suppresses the gap between same-style neighbours, but is deliberately not applied to paragraphs inside table cells, where Word does apply it. **`w:beforeAutospacing`/`w:afterAutospacing`** and the character-unit indent spellings (`w:firstLineChars`, `w:hangingChars`, `w:startChars`, `w:endChars`) are not modelled at all; a document authoring them lays out from whatever literal twip values it also states.
- **Themes, styles, and fonts beyond the accepted resolver inputs:** parse `generic preserved`; model `untyped or unresolved dependencies`; layout `deferred`; edit `deferred`; save `normalized structural preservation`; future gate: typed dependency graph, validated font resources, complete cascade rules, Word comparison fixtures, and paired acceptance.
- **Sections, columns, and pagination rules outside the accepted paragraph boundary:** parse `typed section properties from paragraph-level and body w:sectPr, including all five w:type values and w:cols count/space`; model `enumerated body sections with page size, margins, landscape, titlePage, break type, and a clamped column count`; layout `section-aware pagination with per-section geometry/margins, default/nextPage and continuous breaks, and per-section read-only header/footer furniture`; edit `page size, orientation and margins per section, plus a section-mark insertion that clones the governing w:sectPr — no break-type choice`; save `normalized structural preservation`; future gate: `evenPage`/`oddPage`/`nextColumn` semantics, multi-column flow, break-type selection, save/reopen fixtures for unsupported break types, and paired acceptance. `continuous` sections are implemented and no longer deferred: a continuous boundary shares the preceding sheet, continuing the flow cursor and carrying space-after across. It is conservative rather than complete — sharing requires identical geometry and identical furniture, so a continuous boundary that changes only margins still starts a new sheet where Word continues the current one. `evenPage`, `oddPage`, and `nextColumn` parse but paginate exactly like `nextPage`, with no blank page inserted to reach the requested parity, and a test pins that as the deferred behaviour rather than the Word one. Multi-column (`w:cols`) is read and clamped but never divides the content column, and it is not part of the incremental-layout structure key, so a column change does not even invalidate the cache.
- **Collaboration and replicated undo:** parse `not applicable to DOCX input`; model `replication backend and durable state deferred`; layout `uses only committed local revisions in this slice`; edit `remote operations, awareness, and replicated undo deferred`; save `replicated snapshots/compaction deferred`; future gate: separately specified schema, typed origins, convergence, actor-local undo, durable snapshots, retention/GC, semantic repair, and two-replica conformance.
- **Deterministic PDF, print, and export:** parse `consumes an already accepted canonical model only`; model `no separate authored model allowed`; layout `deterministic shaping and positioned output deferred`; edit `not applicable`; save/export `PDF/print artifacts deferred`; future gate: deterministic font/shaping resources, positioned semantic output contract, backend conformance, and reproducible fixtures independent of browser DOM.
- **Server rendering and language bindings:** parse `headless bounded loading deferred`; model `canonical-tree transport/versioning deferred`; layout `headless layout deferred`; edit `headless commands and language bindings deferred`; save `headless normalized package output deferred`; future gate: browser/headless paragraph parity, resource ports, transport/versioning, server security limits, and language-specific conformance.
- **Public object model, agents, plugins, and MCP expansion:** parse `unchanged existing behavior`; model `new typed-tree facade deferred`; layout `new extension hooks deferred`; edit `new commands deferred`; save `new extension serialization deferred`; future gate: separately specified and versioned public contracts with capability isolation and conformance tests.
