A `List` groups paragraphs that share a numbering definition in one story. Levels use indexes `0` through `8`. Create a `runtime` with [Runtime and setup](/docs/2.x/editor-api/runtime).

## Create a numbered list

Sync after each creation before you configure the returned object:

```ts
await runtime.run(async (context) => {
  const first = context.document.body.insertParagraph('Review contract', 'End');
  await context.sync();
  const list = first.startNewList();
  await context.sync();

  list.setLevelNumbering(0, 'Arabic', [0, '.']);
  list.setLevelStartingNumber(0, 1);
  list.setLevelIndents(0, 36, -18);
  await context.sync();

  list.insertParagraph('Approve changes', 'End');
  await context.sync();
});
```

A new list starts as an independent bullet list with all nine levels defined. `List.insertParagraph(text, location)` accepts `Start`, `End`, `Before`, and `After`, and always inserts inside the list.

## Attach or detach paragraphs

Load the list ID, then attach a paragraph at a defined level:

```ts
const list = context.document.body.lists.getFirst();
list.load('id');
await context.sync();
paragraph.attachToList(list.id, 1);
await context.sync();
```

| Member | Returns or does |
| --- | --- |
| `Body.lists` | `ListCollection` with `items`, `getFirst()`, and `getById(id)` |
| `Paragraph.startNewList()` | A new `List` |
| `Paragraph.attachToList(listId, level)` | The `List` |
| `Paragraph.detachFromList()` | Removes list membership |
| `Paragraph.list` | The paragraph's `List`. Fails with `InvalidArgument` if it has none. |
| `Paragraph.listItem.level` | Reads or writes the level. A missing level refuses. |
| `List.paragraphs`, `List.getLevelParagraphs(level)` | All paragraphs, or those at one level |

A level change removes the paragraph's own left and first-line indents, so it takes the level's indents. Its right indent stays. The subset has no `listString` or `siblingIndex`.

## Configure list levels

| Method | Behavior |
| --- | --- |
| `setLevelBullet(level, listBullet, charCode?, fontName?)` | `ListBullet`: `Custom`, `Solid`, `Hollow`, `Square`, `Diamonds`, `Arrow`, `Checkmark`. `Custom` needs a Unicode code and an available font. |
| `setLevelNumbering(level, listNumbering, formatString?)` | `ListNumbering`: `None`, `Arabic`, `UpperRoman`, `LowerRoman`, `UpperLetter`, `LowerLetter`. Numbers in `formatString` reference levels, such as `[0, '.', 1, ')']`. |
| `setLevelStartingNumber(level, startingNumber)` | Restarts this list instance's counter. |
| `setLevelIndents(level, textIndent, bulletNumberPictureIndent)` | Points. The marker indent is relative to the text indent. |

For example, `list.setLevelBullet(0, 'Custom', 0x2022, 'Calibri')` uses a Calibri bullet. Picture bullets are unavailable.

## Limits

- After list creation syncs, compatible level formatting, paragraph level assignments, and paragraph attachments can share one sync.
- Changes to one level coalesce on its proxy. Different proxies that write the same level conflict.
- With `TrackMineOnly`, creation, membership, and level changes record paragraph property revisions. Definition changes need every member in your own proposed list, so an established list refuses them with `NotSupported`.
- In every mode, instances shared across stories and instances referenced by styles refuse definition edits.
- Protected paragraphs and unsupported numbering structures refuse. Do not remove numbering to force a write.
- For paragraph properties, see [Formatting and styles](/docs/2.x/editor-api/formatting). For list spacing and marker rendering, see [DOCX fidelity](/docs/2.x/docx-fidelity).
