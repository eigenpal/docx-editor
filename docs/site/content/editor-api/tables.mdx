Use `Body.tables` or `Range.tables` to find tables. Create a `runtime` with [Runtime and setup](/docs/2.x/editor-api/runtime), and use document proxies inside `runtime.run()`.

## Insert a table

Insert the table, sync, then configure it:

```ts
await runtime.run(async (context) => {
  const paragraph = context.document.body.paragraphs.getFirst();
  const table = paragraph.insertTable(2, 2, 'After', [
    ['Item', 'Amount'],
    ['License', '$100'],
  ]);
  await context.sync();
  table.headerRowCount = 1;
  await context.sync();
});
```

`Body.insertTable(rowCount, columnCount, location, values?)` takes `Start` or `End`. `Paragraph.insertTable()` and `Range.insertTable()` take `Before` or `After`. Counts must be positive integers, and `values` must be a matching rectangular string matrix.

A new table inside a table cell refuses with `InvalidArgument`. So does `Body.insertTable()` at `Start` when the body already starts with a table. A table inserted at the body's end is followed by an empty paragraph.

## Read table values and cells

Load only the properties you read:

```ts
await runtime.run(async (context) => {
  const table = context.document.body.tables.getFirstOrNullObject();
  table.load(['values', 'rowCount', 'columnCount']);
  await context.sync();
  if (table.isNullObject) return null;
  return table.values;
});
```

| Member | Behavior |
| --- | --- |
| `Table.values` | Read or replace the string matrix. Tables with merged cells allow reads but refuse a whole-table replacement. |
| `TableCell.value` | Read or replace one cell's plain text. Keeps the font formatting. |
| `Table.rowCount`, `Table.columnCount` | Read-only dimensions. |
| `Table.getCell(rowIndex, cellIndex)` | A cell by row and in-row cell index. In merged tables, the cell index differs from the grid column. |
| `Table.rows`, `TableRow.cells` | Collections with `items`, `getFirst()`, and `getFirstOrNullObject()`. |
| `TableCell.body` | The cell's `Body`, for text, paragraphs, search, and formatting. |

Whole-cell replacement refuses multiline values, nested blocks, and complex content. To keep rich content, edit a range inside `TableCell.body`.

## Add or remove rows and columns

Each row or column addition or deletion runs alone in its sync, even across tables:

```ts
await runtime.run(async (context) => {
  const table = context.document.body.tables.getFirst();
  table.rows.load('items');
  await context.sync();
  const source = table.rows.items[1];
  if (!source) throw new Error('Expected an ordinary row after the header');
  source.insertRows('Before', 1, [['Item', 'Price']]);
  await context.sync();
});
```

| Member | Behavior |
| --- | --- |
| `Table.addRows(location, rowCount, values?)` | Adds rows at `Start` or `End`, copying the first or last row. Returns `TableRowCollection`. |
| `TableRow.insertRows(location, rowCount, values?)` | Adds rows `Before` or `After`, copying this row. |
| `Table.addColumns(location, columnCount, values?)` | Adds columns at `Start` or `End`. Returns `void`. Requires a table grid. A merged table refuses `values`: add the columns, sync, then fill the cells. |
| `Table.deleteRows(rowIndex, rowCount?)` | Deletes rows. The default count is one. Works on merged and ragged tables. |
| `Table.deleteColumns(columnIndex, columnCount?)` | Deletes columns. The default count is one. Partial deletion requires a grid. |
| `Table.delete()` | Deletes the table, including merged tables. |

- Deleting every row or column removes the table.
- New cells copy the source cell's paragraph formatting, and new values take its paragraph mark's formatting.
- Row insertion into a table with merged cells requires a table grid.
- Merged source rows, row offsets, hidden source cells, cells outside the grid, and boundaries across vertical merges refuse with `InvalidArgument`.
- Do not combine structural changes with values or formatting. Sync before you use new cells or indexes.

## Merge and split cells

Merge a rectangle, then set the merged cell in the same sync:

```ts
await runtime.run(async (context) => {
  const table = context.document.body.getRange('End').insertTable(3, 3, 'After', [
    ['Quarterly results', '', ''],
    ['Region', 'Q1', 'Q2'],
    ['North', '10', '12'],
  ]);
  await context.sync();
  const header = table.mergeCells(0, 0, 0, 2);
  header.value = 'Quarterly results';
  header.verticalAlignment = 'Center';
  await context.sync();
});
```

| Member | Behavior |
| --- | --- |
| `Table.mergeCells(topRow, firstCell, bottomRow, lastCell)` | Merges the rectangle two cells span, by row and in-row cell index. Returns the merged `TableCell`. `bottomRow` must be at or below `topRow`; either endpoint can lie further left. The rectangle includes complete endpoint merges. |
| `TableCell.split(rowCount, columnCount)` | Splits a cell into equal rows and columns, 1 through 63 each. Returns `void`. The first new cell keeps the content; the others start empty. |

The merged cell keeps each nonempty cell's content as one paragraph. In the merge sync, only `value`, `shadingColor`, and `verticalAlignment` writes on the merged cell work. Other edits in the table refuse with `ConflictingChanges` until you sync.

| Refusal | `innerError.code` | Cause |
| --- | --- | --- |
| `InvalidArgument` | `edit.table-merge-not-rectangle` | A cell crosses the rectangle, or the rectangle holds one cell. |
| `InvalidArgument` | `edit.table-split-unsupported` | Counts the cell cannot take, such as columns below the minimum width, or rows that do not divide a vertical merge. |
| `InvalidArgument` | `edit.unsupported-content` | A `value` write to a merged cell with several paragraphs. |
| `NotImplemented` | None | With tracking off, a cell has a pending row or cell revision. |

## Format cells

Set cell properties on a resolved cell:

```ts
cell.shadingColor = '#EEEEEE';
cell.verticalAlignment = 'Center';
await context.sync();
```

| Property | Values and effects |
| --- | --- |
| `Table.style` | The `nameLocal` of an existing table style. |
| `Table.headerRowCount` | Zero through the row count. Zero removes the header flags. |
| `TableCell.columnWidth` | Finite points. Changes the grid column, matching cells, and table width, and sets fixed layout. |
| `TableCell.shadingColor` | Six-digit RGB hex with optional `#`. `auto` removes direct shading. |
| `TableCell.verticalAlignment` | `Top`, `Center`, or `Bottom`. `Mixed` refuses on writes. `VerticalAlignment` exports the enum. |

In a merged table, a width write changes the last grid column the cell spans. Widths below the minimum, tables without a grid, and legacy horizontal merges refuse. For text formatting, use `cell.body.font` and `cell.body.paragraphs`.

## Suggest table changes

| Operation | With `TrackMineOnly` |
| --- | --- |
| Insert a complete table | Tracks each row, cell paragraph mark, and initial value. Reject removes the table. |
| Replace a cell or table value | Tracked. Refuses in collaboration. |
| Add rows | Tracked as row insertions, with optional values. |
| Delete rows | Tracked, if at least one row stays without a pending deletion. Deleting every row refuses. |
| Merge or split | Only inside your own pending table with no other author's edits. Otherwise `NotSupported` and `edit.tracked-structure-unsupported`. |
| Configure columns and table properties | Only on your own complete proposed table. Existing tables require permanent edits. |

In collaboration, merge and split synchronize, undo, and survive reconnect and reopen, also inside a proposed table.

At a nonempty paragraph's end, a new table goes before the next paragraph when only bookmark or comment ends intervene. A section-ending or pending paragraph mark requires a split.

### Row suggestions

Set `TrackMineOnly` before `Table.addRows()`, `TableRow.insertRows()`, or `Table.deleteRows()`.

| Aspect | Behavior |
| --- | --- |
| Revision types | Row revisions appear in `revisions.items` as `Insert` or `Delete` |
| Persistence | Row revisions survive save and reopen |
| Text edits | A pending row revision blocks tracked text edits in that row |
| Deletion | Rows with pending row or cell structure revisions refuse tracked deletion with `NotImplemented` |

To accept or reject row revisions, see [Tracked changes](/docs/2.x/editor-api/revisions).

## Limits

- Legacy horizontal merges, protected content, preserved structures, and pending revisions can refuse structural edits.
- In collaboration, text typed into an empty cell that another participant merges away is discarded.
- Column edits beyond a shortened row's end leave that row short. They do not fill its missing cells.
- Concurrent merges, splits, and column edits converge, but can leave a row that ends before the last grid column. A merge or split that needs that missing part refuses.
- Independent concurrent row deletions can mark every row. Bulk decisions resolve that result after save and reopen.
- For border and pagination rendering, see [DOCX fidelity](/docs/2.x/docx-fidelity).
