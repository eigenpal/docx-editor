This directory maps every public symbol to the guide that documents it. For exact signatures and enum values, see the [generated API reference](/docs/2.x/api/editor-api) or the declarations for the [root](https://github.com/eigenpal/docx-editor/blob/main/docs/api/docx-editor-editor-api/index.api.md), [browser](https://github.com/eigenpal/docx-editor/blob/main/docs/api/docx-editor-editor-api/browser.api.md), and [agent](https://github.com/eigenpal/docx-editor/blob/main/docs/api/docx-editor-editor-api/agent.api.md) entries.

Get model objects from `context.document`; do not construct them. Members marked `@internal`, including factories and hydration helpers, are unsupported.

## Find host extensions

Host factories, capabilities, previews, input budgets, and collaboration setup are DocxEditor infrastructure, not Office.js add-in APIs. Review item ranges, body-scoped bookmarks and revisions, document notes, typed control values, and nullable review dates differ from Office.js; see [Office.js compatibility](/docs/2.x/editor-api/office-js-api).

| Public symbol | Members or values | Guide |

| `RefreshChangeInput`, `RefreshChange` | `description` for a processor review summary; `diagnostic` with stable codes and the requested anchor | [Document refresh API](/docs/2.x/guides/document-refresh) |

The refresh controller belongs to the browser host. Refresh resets selection and undo history, and refuses collaborative sessions.

## Document properties

The following example sets core document properties:

```ts
await runtime.run(async (context) => {
  const properties = context.document.properties;
  properties.author = 'Public Records Office';
  properties.title = 'Release packet';
  properties.keywords = '';
  await context.sync();
});
```

- `DocumentProperties` exposes string `author`, `title`, `subject`, `keywords`, `comments`, and `category`. Load each before reading.
- Missing properties read as empty strings. An empty assignment clears the value. Unrelated properties stay.
- Values must be XML-safe text of at most 4,096 UTF-16 code units.
- `TrackMineOnly` refuses these writes with `NotSupported`. Dates and custom properties are unsupported.
- `lastAuthor` reads `cp:lastModifiedBy` and has no setter.
- Collaborative writes need an existing core-properties part, because concurrent creation of that part cannot merge. If the input lacks it, set properties before joining collaboration.

### Remove document properties

The following example removes the property parts:

```ts
await runtime.run(async (context) => {
  context.document.removeDocumentInformation('DocumentProperties');
  await context.sync();
});
```

- This removes the standard core, extended, and custom property parts, last-author data, and their relationships. Content, comments, revisions, and media stay.
- Keep it as the only write in its sync.
- Only the `DocumentProperties` mode is supported. Other `RemoveDocInfoType` modes, tracked writes, and collaboration refuse.
- Ambiguous parts, incorrect roots or types, and unknown dependencies refuse with `NotSupported`.
- It does not anonymize text, cached field results, images, or review authors.
