Use this directory to find task examples and runtime limits for the public API. The [generated API reference](/docs/2.x/api/editor-api) provides exact declarations, overloads, and enum values. The repository also publishes generated declarations for the [root entry](https://github.com/eigenpal/docx-editor/blob/main/docs/api/docx-editor-editor-api/index.api.md) and [browser entry](https://github.com/eigenpal/docx-editor/blob/main/docs/api/docx-editor-editor-api/browser.api.md).

A declaration or enum value does not guarantee runtime support for every document or argument. Read the linked guide before choosing an operation. Members marked `@internal`, including factories and hydration helpers, are not supported application APIs. Obtain model objects from `context.document`; do not construct them.

## Distinguish host extensions from Office.js compatibility

Host factories, runtime capabilities, input budgets, and collaboration setup are DocxEditor infrastructure. They do not represent Microsoft Office add-in APIs. Body-scoped bookmarks and revisions, document notes, typed control values, and nullable review dates include documented differences.

## Next steps

See [Office.js compatibility](/docs/2.x/editor-api/office-js-api) before migrating Office.js code. The generated reference remains the declaration authority; runtime notes and tests establish supported behavior.

For integration patterns, see [Connect an agent to a document](/docs/2.x/build-a-docx-agent).

## External document refresh

The refresh controller belongs to the browser host, outside the Office.js document model. `RefreshHighlightOptions` controls change selection and decoration. `NavigateToChangeOptions` controls scroll alignment, motion, padding, and focus. For more information, see [Document refresh API](/docs/2.x/guides/document-refresh).
