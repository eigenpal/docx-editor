Search the smallest body, paragraph, or range that fits your task. Check match counts before you edit, so you do not change the wrong occurrence. For runtime setup, see [Runtime and setup](/docs/2.x/editor-api/runtime).

## Find a unique match

The following example finds whole-word matches and returns their text:

```ts
const found = await runtime.run(async (context) => {
  const matches = context.document.body.search('contract', { matchWholeWord: true });
  matches.load('items/text');
  await context.sync();
  return matches.items.map((match) => match.text);
});
```

`Body.search()`, `Paragraph.search()`, and `Range.search()` return a `RangeCollection` and do not change the document. A paragraph from `getFirst()` or `getLast()` can be searched in the same sync that finds it.

| `SearchOptions` field                          | Behavior                         |
| ---------------------------------------------- | -------------------------------- |
| `matchCase`                                    | Case-sensitive when `true`       |
| `matchWholeWord`                               | Whole words only when `true`     |
| `ignorePunct`, `ignoreSpace`, `matchWildcards` | `true` fails with `NotSupported` |

`RangeCollection` exposes `items`, `getFirst()`, `getLast()`, and `getFirstOrNullObject()`. A non-null accessor fails with `ItemNotFound` when nothing matches.

## Find or create bookmarks

The following example adds a bookmark, then reads it back by name:

```ts
await runtime.run(async (context) => {
  const found = context.document.body.search('Closing Date');
  found.load('items');
  await context.sync();
  if (found.items.length !== 1) throw new Error('Choose one closing date');
  found.items[0]!.insertBookmark('ClosingDate');
  await context.sync();

  const range = context.document.getBookmarkRange('closingdate');
  range.load('text');
  await context.sync();
});
```

| Member | Behavior |
| --- | --- |
| `Body.bookmarks` | `BookmarkCollection` for one story, in document order; no `exists()` |
| `Range.bookmarks` | Bookmarks in the range scope |
| `Bookmark` | Loaded `name`, navigation `range`, `select(selectionMode?)`, and `delete()` |
| `Range.insertBookmark(name)` | Adds a bookmark around the range, or at its position when empty |
| `Range.getBookmarks(includeHidden?, includeAdjacent?)` | `ClientResult<string[]>` of names in or overlapping the range |
| `Document.getBookmarkRange(name)` | Range of the named bookmark; `ItemNotFound` if absent |
| `Document.getBookmarkRangeOrNullObject(name)` | Same, with a null object if absent |
| `Document.deleteBookmark(name)` | Deletes the bookmark and keeps the text; no change if absent |

`Range.insertBookmark(name)` takes a name that starts with a letter, or an underscore for a hidden bookmark. It holds only letters, digits, and underscores, up to 40 characters. Any other name makes `context.sync()` fail with `InvalidArgument`, and nothing in the batch is written. Lookup and deletion accept any name the document already uses.

## Select browser content

The following example selects a bookmark, when the host supports selection:

```ts
if (runtime.capabilities.selection) {
  await runtime.run(async (context) => {
    const range = context.document.getBookmarkRangeOrNullObject('Intro');
    await context.sync();
    if (range.isNullObject) return;
    range.select('Start');
    await context.sync();
  });
}
```

`Range.select()` and `Bookmark.select()` take a `SelectionMode`: `Select` (default), `Start`, or `End`. Selection requires an attached browser document; a server fails with `NotSupported`. The API has no `Document.getSelection()` or separate scrolling method.

A bookmark in a header, footer, or note opens that region first. A read-only editor selects only in the main text and fails with `NotSupported` elsewhere. Selection can share a sync with edits in another region, but not with an operation that must commit alone.

## Behavior notes

- Search matches plain text. Regular expressions are unsupported. Use nonempty search text.
- A query hyphen matches a non-breaking hyphen, and U+2011 compares as a hyphen. An authored optional hyphen does not interrupt a match. A plain U+00AD matches only itself and separates words for `matchWholeWord`.
- Symbols (`w:sym`) never match, and search does not join text across them. For text lengths, see [Read text without exporting proxies](/docs/2.x/editor-api/text-and-ranges#read-text-without-exporting-proxies).
- Search follows the runtime's `revisionTextView`. Cached field results can match, but a match does not permit replacing field or revision structure.
- `Body.search()` does not enter text boxes. Sync the shape's `body` and search it; see [Read and edit text boxes](/docs/2.x/editor-api/page-layout-and-stories#read-and-edit-text-boxes).
- Results keep their original offsets. An edit before a result's end makes it fail with `StaleDocument`. Search again after you edit a matched paragraph; see [Refresh ranges after edits](/docs/2.x/editor-api/text-and-ranges#refresh-ranges-after-edits).
- `Paragraph.split()` changes document structure. For splits, see [Split a paragraph](/docs/2.x/editor-api/text-and-ranges#split-a-paragraph).
- Bookmark names compare without case. Lookup searches the main text, then headers, footers, and notes.
- Each story has its own bookmark collection. No accessor combines stories or exposes document-wide offsets.
- Adding a name that the same story uses moves that bookmark. If another story uses the name, `insertBookmark()` moves it from that story in the same sync.
- With duplicate names, lookup picks the first match in the first matching story. `deleteBookmark()` and `Bookmark.delete()` remove same-name copies from that bookmark's XML part only.
- An untracked replacement removes only bookmark pairs fully inside the replaced text.
- `getBookmarks()` counts a point bookmark inside the range or at its start. An empty range includes the bookmarks that contain its position, without `includeAdjacent`. `includeAdjacent` adds touching bookmarks, and `includeHidden` adds underscore names.
- Bookmarks are not revisions. Under `TrackMineOnly`, bookmark writes apply directly.
- Moving or deleting markers in a content-locked or bound control refuses the whole change.
- If the editor cannot place a selection, `sync()` fails with `NotSupported`, and other writes in that sync can already be committed. Read again; do not repeat those writes.
