Register a component with `definePopup()`. Pass the map through `popups` on the editor root.

Forward session props to the packaged dialog. Replace named parts with `className`, `hidden`, or `asChild`. Use `preset={false}` only for a complete arrangement.

Keep a title, error region, Apply action, and Cancel action. Draft hooks provide values, validation, and actions. Apply commits the draft. Cancel discards it.

Popup entries cover page setup, paragraph settings, links, fields, content controls, revision markup, export, and print feedback.

## React and Vue reference

Pass your DOCX bytes and loaded fonts to this component. The preview uses a fictional contract.

const modules = [reviewModule()];

  return (

## Register your page setup dialog

Create the wrapper in React. Forward the supplied props to retain the editor session.

<FrameworkTabs variant="block">
<Framework value="react">

```tsx
import { DocxEditor, definePopup } from '@docx-editor.dev/react';
import type { DocxEditorPageSetupDialogProps, DocxEditorPopups } from '@docx-editor.dev/react';

function ContractPageSetup(props: DocxEditorPageSetupDialogProps) {
  return (
    <DocxEditor.PageSetupDialog {...props}>
      <DocxEditor.PageSetupDialog.Title>Contract page setup</DocxEditor.PageSetupDialog.Title>
      <DocxEditor.PageSetupDialog.Apply asChild>
        <button type="button" className="contract-apply">
          Apply page settings
        </button>
      </DocxEditor.PageSetupDialog.Apply>
    </DocxEditor.PageSetupDialog>
  );
}

const popups: DocxEditorPopups = {
  pageSetup: definePopup(ContractPageSetup),
};

// Pass this map to the Root in the reference composition.
<DocxEditor.Root document={bytes} fonts={fonts} popups={popups} />;
```

</Framework>
<Framework value="vue">

Create `ContractPageSetup.vue`:

```vue
<script setup lang="ts">
import { DocxEditorPageSetupDialog as Dialog } from '@docx-editor.dev/vue';
import type { DocxEditorPageSetupDialogProps } from '@docx-editor.dev/vue';

const props = withDefaults(defineProps<DocxEditorPageSetupDialogProps>(), {
  preset: true,
});
</script>

<template>
  <Dialog v-bind="props">
    <Dialog.Title>Contract page setup</Dialog.Title>
    <Dialog.Apply as-child>
      <button type="button" class="contract-apply">Apply page settings</button>
    </Dialog.Apply>
  </Dialog>
</template>
```

Register the wrapper in your editor component:

```vue
<script setup lang="ts">
import { DocxEditor, definePopup } from '@docx-editor.dev/vue';
import ContractPageSetup from './ContractPageSetup.vue';

defineProps<{ bytes: Uint8Array }>();
const popups = { pageSetup: definePopup(ContractPageSetup) };
</script>

<template>
  <DocxEditor :document="bytes" :popups="popups" />
</template>
```

</Framework>
</FrameworkTabs>

Vue wrappers must preserve `preset: true` when forwarding omitted Boolean props. The packaged Menu opens Page Setup through its `PageSetup` part. Use `popups.revisionMarkup` for the track changes dialog.

```css

  border: 0;
  border-radius: 999px;
  background: var(--doc-primary);
  color: var(--doc-on-primary);
}
```
