## Choose the API level

| Level                 | Use                                                        |
| --------------------- | ---------------------------------------------------------- |
| Props and CSS tokens  | Change labels, colors, fonts, and viewer preferences.      |
| Named parts           | Arrange controls and replace selected elements.            |
| Hooks and composables | Connect application controls to editor state and commands. |
| Modules               | Add review, collaboration, or custom document nodes.       |

Review controls require an EigenPal Pro License. Toolbar, layout, fonts, and labels also work without the review module. For package setup, see [Installation](/docs/2.x/installation). These examples use application arrangements, not packaged visual presets.

For document extensions, see [Custom nodes](/docs/2.x/pro/custom-nodes). For shared editing, see [Collaboration](/docs/2.x/pro/collaboration).

## React and Vue reference

Pass your DOCX bytes and loaded fonts to this component. The preview uses a fictional contract.

<FrameworkTabs variant="block">
<Framework value="react">

```tsx
import { DocxEditor, type DocxEditorRootProps } from '@docx-editor.dev/react';
import { reviewModule, DocxEditorReview } from '@docx-editor.dev/pro/react';
import '@docx-editor.dev/core/styles/editor.css';

const modules = [reviewModule()];

export function ContractEditor({
  bytes,
  fonts,
}: {
  bytes: Uint8Array;
  fonts: DocxEditorRootProps['fonts'];
}) {
  return (
    <div className="docx-editor contract-workspace">
      <DocxEditor.Root
        document={bytes}
        fonts={fonts}
        modules={modules}
        author="Demo reviewer"
        mode="suggesting"
        reviewDisplayMode="all-markup"
      >
        <DocxEditor.Toolbar preset={false}>
          <DocxEditor.Toolbar.Undo />
          <DocxEditor.Toolbar.Redo />
          <DocxEditor.Toolbar.Bold />
          <DocxEditor.Toolbar.Italic />
          <DocxEditor.Toolbar.EditingMode />
        </DocxEditor.Toolbar>
        <DocxEditor.Viewport style={{ height: 520 }}>
          <DocxEditor.Content />
          <DocxEditor.HyperLink />
          <DocxEditor.ContextMenu />
          <DocxEditorReview />
        </DocxEditor.Viewport>
      </DocxEditor.Root>
    </div>
  );
}
```

</Framework>
