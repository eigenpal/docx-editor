Customize the editor interface with CSS tokens, named parts, and hooks. Start with the smallest change that works.

## Choose a customization API

| Guide | Use it to | API |
| --- | --- | --- |
| [Appearance](/docs/2.x/customization/appearance) | Theme colors and dark mode | `--doc-*` CSS properties, `colorMode` |
| [Layout](/docs/2.x/customization/layout) | Arrange the editor and panels | `DocxEditor.Root`, `.Toolbar`, `.Viewport`, `.Content` |
| [Toolbar](/docs/2.x/customization/toolbar) | Change toolbar controls | Named parts, `Toolbar.Slot`, `Toolbar.Group` |
| [Menus](/docs/2.x/customization/menus) | Change menus | `DocxEditor.Menu`, `DocxEditor.ContextMenu` |
| [Dialogs](/docs/2.x/customization/dialogs) | Replace dialogs | `definePopup()`, `popups` |
| [Tracked changes](/docs/2.x/customization/tracked-changes) | Show tracked changes | Review module settings |
| [Comments and review cards](/docs/2.x/customization/review-cards) | Style review cards | `DocxEditorReview` parts |
| [Document styles](/docs/2.x/customization/document-styles) | Apply paragraph styles | `useParagraphStyle()` |
| [Fonts](/docs/2.x/customization/fonts) | Load fonts | `fonts`, `loadFonts()` |
| [Language and locale](/docs/2.x/customization/language) | Change labels and locale | `LocaleProvider`, `locale` |
| [React hooks](/docs/2.x/react/hooks), [Vue composables](/docs/2.x/vue/composables) | Build your own control | `useEditorCommand(slotId)`, `useEditorState(selector)` |

## Change one control

This toolbar keeps the preset and hides the italic button.

<FrameworkTabs>
<Framework value="react">

```tsx
import { DocxEditor } from '@docx-editor.dev/react';
import '@docx-editor.dev/core/styles/editor.css';

export function Editor({ bytes }: { bytes: Uint8Array }) {
  return (
    <div className="docx-editor contract-workspace">
      <DocxEditor.Root document={bytes}>
        <DocxEditor.Toolbar>
          <DocxEditor.Toolbar.Italic hidden />
        </DocxEditor.Toolbar>
        <DocxEditor.Viewport style={{ height: 520 }}>
          <DocxEditor.Content />
        </DocxEditor.Viewport>
      </DocxEditor.Root>
    </div>
  );
}
```

</Framework>

## Check requirements

- Render every control inside `DocxEditor.Root`, which provides the editor.
- Load `@docx-editor.dev/core/styles/editor.css` before your own CSS.
- Hiding a control does not change operation permissions.
- Interface styling changes controls only. Document styles and fonts can change pagination.
- Review customization requires the review module and an EigenPal Pro License.
