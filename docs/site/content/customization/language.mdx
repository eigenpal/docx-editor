---
title: 'Customize your language'
description: 'Set editor labels and regional formatting independently.'
category: 'Customization'
---

Use `i18n` for interface labels and `locale` for regional formatting. Changing labels does not translate document text.

Import a shipped catalog from `@docx-editor.dev/i18n`. Pass a partial catalog to override selected labels. Missing values fall back to English.

The live selector changes packaged toolbar labels. The contract text and application labels stay in English.

## React and Vue reference

Pass your DOCX bytes and loaded fonts to this component. The preview uses a fictional contract.

<FrameworkTabs variant="block">
<Framework value="react">

```tsx
import { de } from '@docx-editor.dev/i18n';
import { DocxEditor, LocaleProvider, type DocxEditorRootProps } from '@docx-editor.dev/react';
import { reviewModule, DocxEditorReview } from '@docx-editor.dev/pro/react';
import '@docx-editor.dev/core/styles/editor.css';

const modules = [reviewModule()];

export function ContractEditor({
  bytes,
  fonts,
}: {
  bytes: Uint8Array;
  fonts: DocxEditorRootProps['fonts'];
}) {
  return (
    <LocaleProvider i18n={de}>
      <div className="docx-editor contract-workspace">
        <DocxEditor.Root
          document={bytes}
          fonts={fonts}
          modules={modules}
          locale="de-DE"
          author="Demo reviewer"
          mode="suggesting"
          reviewDisplayMode="all-markup"
        >
          <DocxEditor.Toolbar />
          <DocxEditor.Viewport style={{ height: 520 }}>
            <DocxEditor.Content />
            <DocxEditor.HyperLink />
            <DocxEditor.ContextMenu />
            <DocxEditorReview />
          </DocxEditor.Viewport>
        </DocxEditor.Root>
      </div>
    </LocaleProvider>
  );
}
```

</Framework>
<Framework value="vue">

```vue
<script setup lang="ts">
import { de } from '@docx-editor.dev/i18n';
import { DocxEditor, LocaleProvider } from '@docx-editor.dev/vue';
import { reviewModule, DocxEditorReview } from '@docx-editor.dev/pro/vue';
import type { FontConfigurationFragment } from '@docx-editor.dev/vue';
import '@docx-editor.dev/core/styles/editor.css';

defineProps<{ bytes: Uint8Array; fonts: FontConfigurationFragment }>();
const modules = [reviewModule()];
</script>

<template>
  <LocaleProvider :i18n="de">
    <div class="docx-editor contract-workspace">
      <DocxEditor.Root
        :document="bytes"
        :fonts="fonts"
        :modules="modules"
        locale="de-DE"
        author="Demo reviewer"
        mode="suggesting"
        review-display-mode="all-markup"
      >
        <DocxEditor.Toolbar />
        <DocxEditor.Viewport :style="{ height: '520px' }">
          <DocxEditor.Content />
          <DocxEditor.HyperLink />
          <DocxEditor.ContextMenu />
          <DocxEditorReview />
        </DocxEditor.Viewport>
      </DocxEditor.Root>
    </div>
  </LocaleProvider>
</template>
```
