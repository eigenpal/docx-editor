The review module can open each tracked change in a balloon at its text. Start with the built-in balloon. Build your own balloon only when your design needs a different component.

## Use the built-in balloons

Set `revisionsIn` to `'balloons'`. The review pane then lists comments only, and `DocxEditorReview` opens a balloon at the text of each tracked change. The balloon has the author, the date, the changed words, replies, a reply field, and **Accept** and **Reject**.

<Framework value="react">

```tsx
import { DocxEditor } from '@docx-editor.dev/react';
import { reviewModule, DocxEditorReview } from '@docx-editor.dev/pro/react';

const modules = [reviewModule({ pane: { revisionsIn: 'balloons' } })];

<DocxEditor.Root document={bytes} modules={modules} author="Jess Lin">
  <DocxEditor.Viewport style={{ height: 520 }}>
    <DocxEditor.Content />
    <DocxEditorReview />
```

## Build your own balloon

The live example draws an application balloon for tracked changes. It opens when you click a tracked change.

<CustomizationDemo topic="balloons" />

Keep `revisionsIn: 'balloons'` and pass `hidden` to `DocxEditorReview.Balloon`. The review pane then lists comments only, the built-in balloon stays closed, and your balloon is the route to each tracked change. The built-in format and structural change balloons go with it, so your balloon handles every revision kind.

Read the item and its position from the editor, not from the painted pages:

- On a click, call `editor.getReviewItemsAt(event.clientX, event.clientY, { pairReplacements: true })`. It returns the review items under the point, innermost first. Open the first revision. Do not call `setActive` on a click, because it moves the caret to the start of the change.
- To place the balloon, call `editor.getReviewItemRects(key)`. It returns the painted bands of the item in client coordinates. Anchor the balloon to the first band. If the array is empty, the item has no painted text, so hide the balloon. Read the bands again after a scroll, a resize, each `change` event, a zoom change, and when the review pane opens or closes.
- To follow **Next Change** and **Previous Change**, listen for `reviewItemReveal` with `useEditorEvent`. Navigation steps through the unpaired queue, so for a replacement the event's `key` names one half. The event also carries `pairKey`, the key of the pair, so open `pairKey ?? key`. You can read `activatedKey` from `useReview()` instead. Do not open the balloon for `activeKey`. It follows the caret, so the balloon opens each time the caret lands in a change.
- Pass the same query, `{ pairReplacements: true }`, to `useReview()` and to the hit test, so that a hit names an item in your list. A replacement is then one item with `revisionKind: 'replace'`.
- Check the Boolean that `accept` and `reject` return. Handle Escape, dismissal, read-only items, and cleanup.

## Build the balloon

Create `ContractBalloons.tsx` or `ContractBalloons.vue` with these examples. Both use the same placement helper. Set `authorAccent` in React or `author-accent` in Vue to tint the balloon by author.

<FrameworkTabs variant="block">
<Framework value="react">

```tsx
'use client';

import { useEffect, useRef, useState, type RefObject } from 'react';
import { useDocxEditor, useEditorEvent, useReviewAuthors } from '@docx-editor.dev/react';
import { useReview } from '@docx-editor.dev/pro/react';
import { revisionLabel, watchBalloonAnchor, type BalloonPosition } from './watch-balloon-anchor';

/** One key for a replacement, in the hit test and in the review queue. */
const query = { pairReplacements: true };

/** Application-owned balloons for tracked changes. */
export function ContractBalloons({
  container,
  rounded,
  authorAccent = false,
}: {
  container: RefObject<HTMLDivElement | null>;
  rounded: boolean;
  authorAccent?: boolean;
}) {
  const editor = useDocxEditor();
  const { items, accept, reject } = useReview(query);
  const authors = useReviewAuthors();
  const panel = useRef<HTMLDivElement>(null);
  const [openKey, setOpenKey] = useState<string | null>(null);
  const [position, setPosition] = useState<BalloonPosition | null>(null);
  const [failure, setFailure] = useState('');
  const item = items.find((entry) => entry.key === openKey && entry.kind === 'revision');
  const itemKey = item?.key;

  // Next Change and Previous Change ask the host to open an item.
  // Navigation names one half of a replacement; pairKey names the pair in `items`.
  useEditorEvent('reviewItemReveal', ({ key, pairKey }) => {
    setFailure('');
    setOpenKey(pairKey ?? key);
  });

  useEffect(() => {
    const host = container.current;
    if (!host || !editor) return;
    const click = (event: MouseEvent) => {
      if (event.target instanceof Node && panel.current?.contains(event.target)) return;
      // Read the item under the pointer. Do not activate it: that moves the caret.
      const hit = editor
        .getReviewItemsAt(event.clientX, event.clientY, query)
        .find((entry) => entry.placement.kind === 'revision');
      setFailure('');
      setOpenKey(hit?.placement.key ?? null);
    };
    const keydown = (event: KeyboardEvent) => {
      if (event.key === 'Escape') setOpenKey(null);
    };
    host.addEventListener('click', click);
    host.addEventListener('keydown', keydown);
    return () => {
      host.removeEventListener('click', click);
      host.removeEventListener('keydown', keydown);
    };
  }, [container, editor]);

  useEffect(() => {
    const host = container.current;
    if (!host || !editor || !itemKey) {
      setPosition(null);
      return;
    }
    return watchBalloonAnchor(editor, host, itemKey, setPosition);
  }, [container, editor, itemKey]);

  if (!item || item.kind !== 'revision' || !position) return null;
  const authorColor =
    authors.find((author) => author.author === item.author)?.color ?? 'var(--doc-primary)';
  return (
    <div
      ref={panel}
      className="contract-balloon"
      style={{
        ...position,
        borderRadius: rounded ? 16 : 4,
        borderInlineStart: authorAccent ? `3px solid ${authorColor}` : undefined,
        background: authorAccent
          ? `color-mix(in srgb, ${authorColor} 8%, var(--doc-surface))`
          : undefined,
      }}
      data-review-author={item.author}
      role="group"
      aria-label="Tracked change balloon"
      onMouseDown={(event) => event.preventDefault()}
    >
      <div className="contract-balloonHeading">
        <span className="contract-initials">{item.initials}</span>
        <strong>{item.author}</strong>
        <button type="button" aria-label="Close balloon" onClick={() => setOpenKey(null)}>
          ×
        </button>
      </div>
      <p>{revisionLabel(item.revisionKind)}</p>
      {item.replacedText && (
        <p className="contract-excerpt">
          <del>{item.replacedText}</del>
        </p>
      )}
      <p className="contract-excerpt">{item.text}</p>
      <div className="contract-decisions">
        <button
          type="button"
          disabled={item.readOnly}
          onClick={() => {
            if (!accept(item))
              setFailure('The editor refused this change. Review the document and try again.');
          }}
        >
          Accept
        </button>
        <button
          type="button"
          disabled={item.readOnly}
          onClick={() => {
            if (!reject(item))
              setFailure('The editor refused this change. Review the document and try again.');
          }}
        >
          Reject
        </button>
      </div>
      {failure && <p role="alert">{failure}</p>}
    </div>
  );
}
```

```vue
<script setup lang="ts">
import { computed, ref, watchEffect } from 'vue';
import { useDocxEditor, useEditorEvent, useReviewAuthors } from '@docx-editor.dev/vue';
import { useReview } from '@docx-editor.dev/pro/vue';
import { revisionLabel, watchBalloonAnchor } from './watch-balloon-anchor';
import type { BalloonPosition } from './watch-balloon-anchor';

/** One key for a replacement, in the hit test and in the review queue. */
const query = { pairReplacements: true };

const props = defineProps<{
  container: HTMLElement | null;
  authorAccent?: boolean;
}>();
const editor = useDocxEditor();
const authors = useReviewAuthors();
const { items, accept, reject } = useReview(query);
const panel = ref<HTMLElement | null>(null);
const openKey = ref<string | null>(null);
const position = ref<BalloonPosition | null>(null);
const failure = ref('');
const item = computed(() =>
  items.value.find((entry) => entry.key === openKey.value && entry.kind === 'revision')
);

const authorColor = computed(
  () =>
    authors.value.find((author) => author.author === item.value?.author)?.color ??
    'var(--doc-primary)'
);

// Next Change and Previous Change ask the host to open an item.
// Navigation names one half of a replacement; pairKey names the pair in `items`.
useEditorEvent('reviewItemReveal', ({ key, pairKey }) => {
  failure.value = '';
  openKey.value = pairKey ?? key;
});

watchEffect((cleanup) => {
  const host = props.container;
  const view = editor.value;
  if (!host || !view) return;
  const click = (event: MouseEvent) => {
    if (event.target instanceof Node && panel.value?.contains(event.target)) return;
    // Read the item under the pointer. Do not activate it: that moves the caret.
    const hit = view
      .getReviewItemsAt(event.clientX, event.clientY, query)
      .find((entry) => entry.placement.kind === 'revision');
    failure.value = '';
    openKey.value = hit?.placement.key ?? null;
  };
  const keydown = (event: KeyboardEvent) => {
    if (event.key === 'Escape') openKey.value = null;
  };
  host.addEventListener('click', click);
  host.addEventListener('keydown', keydown);
  cleanup(() => {
    host.removeEventListener('click', click);
    host.removeEventListener('keydown', keydown);
  });
});
watchEffect((cleanup) => {
  const host = props.container;
  const view = editor.value;
  const key = item.value?.key;
  if (!host || !view || !key) {
    position.value = null;
    return;
  }
  cleanup(
    watchBalloonAnchor(view, host, key, (value) => {
      position.value = value;
    })
  );
});
function decide(kind: 'accept' | 'reject') {
  const active = item.value;
  if (!active || active.kind !== 'revision') return;
  if (!(kind === 'accept' ? accept(active) : reject(active))) {
    failure.value = 'The editor refused this change. Review the document and try again.';
  }
}
</script>

<template>
  <div
    v-if="item?.kind === 'revision' && position"
    ref="panel"
    class="contract-balloon"
    role="group"
    aria-label="Tracked change balloon"
    :data-review-author="item.author"
    :style="{
      left: `${position.left}px`,
      top: `${position.top}px`,
      borderInlineStart: authorAccent ? `3px solid ${authorColor}` : undefined,
      background: authorAccent
        ? `color-mix(in srgb, ${authorColor} 8%, var(--doc-surface))`
        : undefined,
    }"
    @mousedown.prevent
  >
    <strong>{{ item.author }}</strong>
    <button type="button" aria-label="Close balloon" @click="openKey = null">×</button>
    <p>{{ revisionLabel(item.revisionKind) }}</p>
    <p v-if="item.replacedText">
      <del>{{ item.replacedText }}</del>
    </p>
    <p>{{ item.text }}</p>
    <button type="button" :disabled="item.readOnly" @click="decide('accept')">Accept</button>
    <button type="button" :disabled="item.readOnly" @click="decide('reject')">Reject</button>
    <p v-if="failure" role="alert">{{ failure }}</p>
  </div>
</template>
```

## Place the balloon

Create `watch-balloon-anchor.ts` beside the balloon component. The helper reads the bands of the item from the editor with `getReviewItemRects(key)`, so it reads no painted page markup. It places the balloon under the first band, relative to your container. It reads the bands again after a scroll, a resize, each document change, a zoom change, and when the review pane opens or closes. It hides the balloon when the item has no painted band.

```ts
import type { Editor } from '@docx-editor.dev/core';

export interface BalloonPosition {
  left: number;
  top: number;
}

/** Places a balloon under the first painted band of one review item. */
export function watchBalloonAnchor(
  editor: Editor,
  host: HTMLElement,
  key: string,
  notify: (position: BalloonPosition | null) => void
): () => void {
  let frame = 0;
  function update() {
    frame = 0;
    const [band] = editor.getReviewItemRects(key);
    const bounds = host.getBoundingClientRect();
    if (!band || band.bottom < bounds.top || band.top > bounds.bottom) {
      notify(null);
      return;
    }
    const width = Math.min(280, host.clientWidth - 24);
    notify({
      left: Math.max(12, Math.min(band.left - bounds.left, host.clientWidth - width - 12)),
      top: band.bottom - bounds.top + 8,
    });
  }
  function schedule() {
    if (!frame) frame = requestAnimationFrame(update);
  }
  update();
  const resize = new ResizeObserver(schedule);
  resize.observe(host);
  host.addEventListener('scroll', schedule, true);
  const offChange = editor.on('change', schedule);
  // Zoom and the review pane move the pages without a document change.
  let { zoom, reviewPaneOpen } = editor.snapshot();
  const offView = editor.on('selectionChange', (snapshot) => {
    if (snapshot.zoom === zoom && snapshot.reviewPaneOpen === reviewPaneOpen) return;
    ({ zoom, reviewPaneOpen } = snapshot);
    schedule();
  });
  return () => {
    cancelAnimationFrame(frame);
    resize.disconnect();
    host.removeEventListener('scroll', schedule, true);
    offChange();
    offView();
  };
}

/** A short heading for each kind of tracked change. */
export function revisionLabel(kind: string): string {
  if (kind === 'insert') return 'Inserted text';
  if (kind === 'delete') return 'Deleted text';
  if (kind === 'replace') return 'Replaced text';
  return 'Tracked change';
}
```

## Style the balloon

Load these application rules after the editor stylesheet. Both framework examples use the same container and balloon classes.

```css
.contract-stage {
  position: relative;
  min-height: 0;
}
.docx-editor .contract-balloon {
  position: absolute;
  z-index: 40;
  width: min(280px, calc(100% - 24px));
  padding: 14px;
  border: 1px solid var(--doc-border);
  border-radius: 16px;
  background: var(--doc-surface);
  color: var(--doc-text);
  box-shadow: 0 12px 32px var(--doc-border);
}
.docx-editor .contract-balloon button {
  margin: 4px;
  padding: 5px 8px;
  border: 1px solid var(--doc-border);
  border-radius: 6px;
  background: var(--doc-bg);
  color: var(--doc-text);
}
.docx-editor .contract-balloon button:focus-visible {
  outline: 2px solid var(--doc-primary);
  outline-offset: 3px;
}
```

A replacement records a deletion and an insertion. With `useReview({ pairReplacements: true })`, the balloon shows them as one item, and **Accept** and **Reject** decide both. For more information, see [Show a replacement as one item](/docs/2.x/pro/tracked-changes#show-a-replacement-as-one-item).
