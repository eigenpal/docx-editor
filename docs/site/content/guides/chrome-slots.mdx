Chrome slots are stable control identifiers, such as `text.bold`. Use named parts, such as `FontColor` or `ImageProperties`, for controls that collect a value or open UI.

## Use a slot

Render a fixed-command slot that has no named part with the generic toolbar button.

<FrameworkTabs>
<Framework value="react">

```tsx
<DocxEditor.Toolbar.Button slotId="format.painter" />
```

</Framework>
<Framework value="vue">

```vue
<DocxEditorToolbar.Button slot-id="format.painter" />
```

</Framework>
</FrameworkTabs>

`Toolbar.Button`, `Menu.Item`, and `ContextMenu.Slot` take the ID as `slotId` (`slot-id` in Vue templates). The `slot` prop is deprecated and logs a development warning.

| Column | Meaning |
| --- | --- |
| **Packaged surface** | Where the standard editor places the control. **Explicit composition** means you add the named part yourself. |
| **Toolbar part** | The shared suffix. `Bold` means `DocxEditor.Toolbar.Bold` in React and `DocxEditorToolbar.Bold` in Vue. An em dash means no named part. |

For `Action`, `Group`, `Slot`, and `Separator`, see [Customize the toolbar](/docs/2.x/guides/toolbar).

### Alignment, direction, lists, and formatting

The default toolbar combines the four alignment slots into `Alignment`. Use the four `Align*` parts when you want separate controls.

Alignment slots name a physical edge, not a reading direction. In a right-to-left paragraph, `alignment.right` writes the leading edge, which OOXML spells `w:jc="left"`. For more information, see [Right-to-left support](/docs/2.x/guides/right-to-left).

The direction slots set the base direction of each selected paragraph and show a mixed selection as neither pressed. The default toolbar shows them only when the interface direction is `'rtl'`.

| Slot | Packaged surface | Toolbar part | Purpose |
| --- | --- | --- | --- |
| `alignment.left` | Default toolbar | `Alignment`, `AlignLeft` | Align left |
| `alignment.center` | Default toolbar | `AlignCenter` | Align center |
| `alignment.right` | Default toolbar | `AlignRight` | Align right |
| `alignment.justify` | Default toolbar | `AlignJustify` | Justify |
| `direction.ltr` | Default toolbar (RTL interface) | `LeftToRight` | Left-to-right paragraph |
| `direction.rtl` | Default toolbar (RTL interface) | `RightToLeft` | Right-to-left paragraph |
| `list.bullet` | Default toolbar | `BulletList` | Toggle a bulleted list |

## Check command requirements

A slot's existence does not guarantee that its command is available.

| Slot kind | How to run it |
| --- | --- |
| Fixed command | `useEditorCommand(slotId)` returns `execute()`, active state, enabled state, and the engine's disabled reason. |
| Value or dialog control | Pass a complete `EditorCommand` to `useEditorCommand()`, or use the packaged part or menu. |
| File action | `file.open` and `file.save` need the loading and saving APIs. Export and print slots need `menu.exporters` handlers. |

For complete signatures, see the [core API reference](/docs/2.x/api/core), [React API reference](/docs/2.x/api/react), or [Vue API reference](/docs/2.x/api/vue).
