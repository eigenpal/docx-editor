Every field of the Format shape pane and the Chart pane is a slot and a part. A slot is a command with an enabled state and a value. A part is a ready control for one slot. You can place parts anywhere inside `DocxEditor.Root`: a toolbar, a popover, a drawer, or a pane of your own. The parts follow the selection and repaint when another control changes the object.

## Add controls to your toolbar

Each part takes a `variant`. Use `variant="compact"` in a toolbar: the label is for screen readers only, and the disabled reason shows in the tooltip. The default `variant="field"` shows a visible label and the disabled reason under the control.

The following toolbar adds the fill color and the outline dash of the selected shape:

```tsx
import { DocxEditor } from '@docx-editor.dev/react';

function ShapeToolbar() {
  return (
    <div role="toolbar" aria-label="Shape">
      <DocxEditor.ShapeFill variant="compact" />
      <DocxEditor.ShapeOutlineDash variant="compact" />
    </div>
  );
}
```

When no shape is selected, the parts are disabled and give the reason.

## Use a slot without a part

To render your own control, read the slot with `useObjectControl`. It returns `value`, `isActive`, `isEnabled`, `disabledReason`, `label`, and three ways to run the slot: `execute`, `apply`, and `toggle`. `apply` returns the translated refusal, or `null` when the change applied.

```tsx
import { useObjectControl } from '@docx-editor.dev/react';

function AccentFillButton() {
  const fill = useObjectControl('shape.fill');
  return (
    <button
      type="button"
      disabled={!fill.isEnabled}
      title={fill.disabledReason ?? fill.label}
      aria-pressed={fill.value === 'accent1'}
      onClick={() => fill.execute('accent1')}
    >
      Accent fill
    </button>
  );
}
```

Outside React, run a slot with `runToolbarCommand`, and read its state with `toolbarCommandState`:

```ts
import { runToolbarCommand } from '@docx-editor.dev/core/editor';

const result = runToolbarCommand(editor, 'shape.outlineDash', 'dash');
if (!result.ok) console.warn(result.reason);
```

## Show pane sections in a popover

Insert > Chart, **Edit chart**, and **Format shape** send a pane request. Any UI can answer it. `usePaneRequest` calls your listener for the panes that `panes` names. `DocxEditor.PaneSections` renders the sections of a pane, each a heading over its parts.

The following popover answers the chart request with the type and elements sections:

```tsx
import { useState } from 'react';
import { DocxEditor, usePaneRequest } from '@docx-editor.dev/react';

function ChartPopover() {
  const [open, setOpen] = useState(false);
  usePaneRequest(() => setOpen(true), { panes: ['chart'] });
  if (!open) return null;
  return (
    <div role="dialog" aria-label="Chart">
      <DocxEditor.PaneSections pane="chart" sections={['type', 'elements']} />
      <button type="button" onClick={() => setOpen(false)}>
        Close
      </button>
    </div>
  );
}
```

`PANE_SECTIONS` lists the sections and their slots:

| Pane | Section | Slots |
| --- | --- | --- |
| `shape` | `fill` | `shape.fill`, `shape.fillTransparency` |
| `shape` | `outline` | `shape.outlineColor`, `shape.outlineWidth`, `shape.outlineDash` |
| `chart` | `type` | `chart.type` |
| `chart` | `elements` | `chart.title`, `chart.legend`, `chart.dataLabels`, `chart.axes`, `chart.gridlines`, `chart.categoryAxisTitle`, `chart.valueAxisTitle` |
| `chart` | `colors` | `chart.seriesColor` |
| `chart` | `data` | `chart.data` |

## Build a pane from parts

Combine sections and single parts into your own pane or drawer. A part for an element that the chart type does not have renders nothing. For example, `ChartAxes` renders nothing for a pie chart.

```tsx
import { DocxEditor } from '@docx-editor.dev/react';

function ChartDrawer() {
  return (
    <aside aria-label="Chart">
      <DocxEditor.ChartType />
      <DocxEditor.ChartTitle />
      <DocxEditor.ChartLegend />
      <DocxEditor.ChartDataLabels />
      <DocxEditor.ChartAxes />
      <DocxEditor.ChartGridlines />
      <DocxEditor.ChartCategoryAxisTitle />
      <DocxEditor.ChartValueAxisTitle />
      {/* index shows one series; omit it to show every series */}
      <DocxEditor.ChartSeriesColors index={0} />
      <DocxEditor.ChartData />
    </aside>
  );
}
```

To insert a chart from your own UI, place `DocxEditor.ChartInsert`. It is the chart type list of the `insert.chart` slot, with `Trigger`, `Content`, and `Item` parts.

## Use the color picker

The fill, outline, and series color parts use the `ColorPicker` compound. You can use it for your own color controls. It has these parts:

- `ColorPicker.Root` holds the value and the open state, and calls `onPick`.
- `ColorPicker.Trigger` opens the grid.
- `ColorPicker.Content` is the grid: No color, theme colors with tints and shades, standard colors, and a hex field.
- `ColorPicker.Swatch`, `ColorPicker.NoColor`, and `ColorPicker.HexInput` are the parts of the grid.

A theme pick such as `accent1:40` saves as a theme color reference on shapes and charts. On a table border or shading, it saves as an RGB value. The following control sets the shape outline color:

```tsx
import { DocxEditor, useObjectControl, type ColorPickerValue } from '@docx-editor.dev/react';

function OutlineColor() {
  const outline = useObjectControl('shape.outlineColor');
  return (
    <DocxEditor.ColorPicker.Root
      value={(outline.value ?? null) as ColorPickerValue}
      disabled={!outline.isEnabled}
      onPick={(pick) => outline.apply(pick)}
    >
      <DocxEditor.ColorPicker.Trigger aria-label={outline.label} />
      <DocxEditor.ColorPicker.Content />
    </DocxEditor.ColorPicker.Root>
  );
}
```

To build your own grid, put `ColorPicker.NoColor`, `ColorPicker.Swatch` with a `pick`, and `ColorPicker.HexInput` inside `ColorPicker.Content`.

## Use the controls in Vue

Vue exposes the same parts on the `DocxEditor` namespace, and the same `useObjectControl` and `usePaneRequest` composables. The composables return refs.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocxEditor, usePaneRequest } from '@docx-editor.dev/vue';

const open = ref(false);
usePaneRequest(() => (open.value = true), { panes: ['chart'] });
</script>

<template>
  <div role="toolbar" aria-label="Shape">
    <DocxEditor.ShapeFill variant="compact" />
    <DocxEditor.ShapeOutlineDash variant="compact" />
  </div>
  <div v-if="open" role="dialog" aria-label="Chart">
    <DocxEditor.PaneSections pane="chart" :sections="['type', 'elements']" />
  </div>
</template>
```

## Slot reference

`runToolbarCommand` and `execute` take these values. `ObjectSlotValueMap` holds the same types.

| Slot | Value |
| --- | --- |
| `shape.fill` | A color pick (`accent1:40`, `#4472C4`), or `none` for No fill |
| `shape.fillTransparency` | A whole percent from 0 (opaque) to 100 (clear) |
| `shape.outlineColor` | A color pick, or `none` for No line |
| `shape.outlineWidth` | Points, from 0.25 to 1584 |
| `shape.outlineDash` | A `ShapeOutlineDash` preset, such as `solid`, `sysDot`, `dash`, or `lgDashDotDot` |
| `chart.type` | A `ChartType`, such as `columnClustered`, `line`, or `pie` |
| `chart.title` | The title text; empty text or `null` removes the title |
| `chart.legend` | A `ChartLegendPosition`, such as `right`, `bottom`, or `none` |
| `chart.dataLabels` | `true` or `false`; with no value, the slot toggles |
| `chart.axes` | `true` or `false`; with no value, the slot toggles |
| `chart.gridlines` | `true` or `false`; with no value, the slot toggles |
| `chart.categoryAxisTitle` | The axis title; empty text or `null` removes it |
| `chart.valueAxisTitle` | The axis title; empty text or `null` removes it |
| `chart.seriesColor` | `{ index, color }`, where `color` is a color pick or `auto` |
| `chart.data` | One `ChartPaneChange`, or the whole data without `workbook` |

The outline dash list offers eight presets: `solid`, `sysDot`, `sysDash`, `dash`, `dashDot`, `lgDash`, `lgDashDot`, and `lgDashDotDot`. The command accepts all 11 `ST_PresetLineDashVal` values. The dash saves as `a:prstDash`, and as `v:stroke/@dashstyle` on VML shapes.

Note these facts about the slots:

- The default toolbar adds the shape group when you select a shape, and the chart group when you select a chart. Each group shows only its compact controls; the other slots stay in the panes. For the full table, see [Chrome slot reference](/docs/2.x/guides/chrome-slots#shapes-and-charts).
- Diagrams use the `image.*` slots of the image group. They have no slots of their own.
- The chart color helpers, such as `chartColorGrid` and `chartColorLabel`, stay as deprecated aliases of the color picker names.
