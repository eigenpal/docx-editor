Set `colorMode` to change the editor controls and document preview.

## Enabling dark mode

`colorMode` is a controlled prop. There is no internal toggle button; you set the value and the editor uses that value.

| Value | Behavior |
| --- | --- |
| `'light'` | Light theme (default). |
| `'dark'` | Dark theme. |
| `'system'` | Follows the operating system via `prefers-color-scheme`, and updates live when the OS theme changes. |

<FrameworkTabs>
<Framework value="react">

```tsx
<DocxEditor document={bytes} colorMode="dark" />
```

</Framework>
<Framework value="vue">

```vue
<DocxEditor :document="bytes" color-mode="dark" />
```

</Framework>

## Toggling from your own UI

Connect `colorMode` to an application switch, settings menu, or segmented button. The editor applies the new theme when the value changes.

<FrameworkTabs>
<Framework value="react">

```tsx
import { useState } from 'react';
import { DocxEditor } from '@docx-editor.dev/react';

export function ThemedEditor({ bytes }: { bytes: Uint8Array }) {
  const [colorMode, setColorMode] = useState<'light' | 'dark'>('light');

  return (
    <>
      <button
        type="button"
        onClick={() => setColorMode((mode) => (mode === 'dark' ? 'light' : 'dark'))}
      >
        Toggle theme
      </button>
      <DocxEditor document={bytes} colorMode={colorMode} />
    </>
  );
}
```

</Framework>
<Framework value="vue">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocxEditor } from '@docx-editor.dev/vue';

defineProps<{ bytes: Uint8Array }>();
const colorMode = ref<'light' | 'dark'>('light');
</script>

<template>
  <button type="button" @click="colorMode = colorMode === 'dark' ? 'light' : 'dark'">
    Toggle theme
  </button>
  <DocxEditor :document="bytes" :color-mode="colorMode" />
</template>
```

</Framework>
</FrameworkTabs>

To follow the operating system instead, pass `colorMode="system"`.

## What dark mode changes

Dark mode changes the editor controls and the document preview:

- Editor controls use the shared color tokens.
- The document preview adjusts color lightness while preserving hue.
- Embedded images retain their original colors.

The preview transform does not change authored colors or saved DOCX bytes. Printing uses document colors and ignores `colorMode`.

## Reporting issues

The document preview uses a color transform that can reduce contrast in some documents. If a control does not use the theme correctly, open an issue at [GitHub issues](https://github.com/eigenpal/docx-editor/issues). Also report text with low contrast or colors that transform incorrectly. Mention `colorMode` and include a screenshot.
