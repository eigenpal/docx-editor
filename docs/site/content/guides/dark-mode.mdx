## Set the color mode

Pass `colorMode` to the editor.

<FrameworkTabs>
<Framework value="react">

```tsx
<DocxEditor document={bytes} colorMode="dark" />
```

</Framework>
<Framework value="vue">

```vue
<DocxEditor :document="bytes" color-mode="dark" />
```

</Framework>
</FrameworkTabs>

| Value      | Behavior                                                                            |
| ---------- | ----------------------------------------------------------------------------------- |
| `'light'`  | Light theme (default).                                                              |
| `'dark'`   | Dark theme.                                                                         |
| `'system'` | Follows `prefers-color-scheme` and updates when the operating system theme changes. |

## Connect your application theme

`colorMode` is a controlled prop. The editor has no internal toggle, so your application owns the value.

<FrameworkTabs>
<Framework value="react">

```tsx
import { useState } from 'react';
import { DocxEditor } from '@docx-editor.dev/react';

export function ThemedEditor({ bytes }: { bytes: Uint8Array }) {
  const [colorMode, setColorMode] = useState<'light' | 'dark'>('light');

  return (
    <>
      <button
        type="button"
        onClick={() => setColorMode((mode) => (mode === 'dark' ? 'light' : 'dark'))}
      >
        Toggle theme
      </button>
      <DocxEditor document={bytes} colorMode={colorMode} />
    </>
  );
}
```

</Framework>
<Framework value="vue">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocxEditor } from '@docx-editor.dev/vue';

defineProps<{ bytes: Uint8Array }>();
const colorMode = ref<'light' | 'dark'>('light');
</script>

<template>
  <button type="button" @click="colorMode = colorMode === 'dark' ? 'light' : 'dark'">
    Toggle theme
  </button>
  <DocxEditor :document="bytes" :color-mode="colorMode" />
</template>
```

</Framework>
</FrameworkTabs>

In a composed editor, set `colorMode` on the root. Every part inside it uses the same theme.

<FrameworkTabs>
<Framework value="react">

```tsx
<DocxEditor.Root document={bytes} colorMode="system">
  <DocxEditor.Toolbar />
  <DocxEditor.Viewport>
    <DocxEditor.Content />
  </DocxEditor.Viewport>
</DocxEditor.Root>
```

</Framework>
<Framework value="vue">

```vue
<DocxEditorRoot :document="bytes" color-mode="system">
  <DocxEditorToolbar />
  <DocxEditorViewport>
    <DocxEditorContent />
  </DocxEditorViewport>
</DocxEditorRoot>
```

</Framework>
</FrameworkTabs>

A `dark` class outside the editor, such as on `html`, does not select the editor color tokens. A few utility variants and the drawing placeholder card still react to it. Pass your application theme to `colorMode` instead.

## Theme custom controls

Read the resolved mode in parts that you build, such as a side panel.

<FrameworkTabs>
<Framework value="react">

```tsx
import { useEditorColorMode } from '@docx-editor.dev/react';

function NotesPanel() {
  const { colorMode } = useEditorColorMode();
  return <aside className={colorMode === 'dark' ? 'notes notes--dark' : 'notes'} />;
}
```

</Framework>
<Framework value="vue">

```ts
import { computed } from 'vue';
import { useEditorColorMode } from '@docx-editor.dev/vue';

const { colorMode } = useEditorColorMode();
const notesClass = computed(() => (colorMode.value === 'dark' ? 'notes notes--dark' : 'notes'));
```

</Framework>
</FrameworkTabs>

| Hook | Returns |
| --- | --- |
| `useEditorColorMode()` | `{ colorMode }`, the resolved `'light'` or `'dark'`. With `'system'`, it follows the operating system. |
| `useScopeClassName()` | A class name that includes `dark` under a dark root. Parts that use `--doc-*` tokens follow the theme. |

For the color tokens, see [Appearance](/docs/2.x/customization/appearance).

## Limits

- With `'system'`, a server render and the first browser render report `'light'`. The value updates after the editor reads the setting.
- Outside the editor root, or when the root has no `colorMode`, `useEditorColorMode()` returns `'light'`.
- The packaged editor with `chrome={false}` also reports `'light'`. Read your own `colorMode` value there.
- The document preview changes color lightness and keeps hue. Images keep their original colors.
- The preview does not change authored colors or saved DOCX bytes.
- Printing uses document colors and ignores `colorMode`.
