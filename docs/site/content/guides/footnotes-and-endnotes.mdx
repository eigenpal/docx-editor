The editor renders DOCX footnotes and endnotes in their document locations and edits note text on the same surface.

## Insert a note

Run `insertNote` to add a reference at the caret and open the new note body:

```ts
editor.exec({ type: 'insertNote', noteKind: 'footnote' });
```

| `noteKind` | Chrome slot       |
| ---------- | ----------------- |
| `footnote` | `insert.footnote` |
| `endnote`  | `insert.endnote`  |

React and Vue share these slots. The **Insert** menu offers the same commands. In suggesting mode, the inserted reference is tracked.

## Read and edit notes

Use the Office.js-shaped `Body.footnotes` and `Body.endnotes` collections in automation. Read note text in two batches:

```ts
const notes = await runtime.run(async (context) => {
  const collection = context.document.body.footnotes;
  collection.load('items');
  await context.sync();
  for (const note of collection.items) note.load(['type', 'text']);
  await context.sync();
  return collection.items.map((note) => ({ type: note.type, text: note.text }));
});
```

Use `note.body` to edit a note. Separate writes to different notes with `context.sync()`. `Document.footnotes` and `Document.endnotes` are DocxEditor extensions, outside the Office.js document model.

In the browser, these APIs expose the active note:

| API                      | Purpose                                      |
| ------------------------ | -------------------------------------------- |
| `useNoteScopeState()`    | Reads the active note scope in React or Vue. |
| `DocxEditor.NotesChrome` | Packaged note controls for React.            |
| `DocxEditorNotesChrome`  | Packaged note controls for Vue.              |

Text, lists, tables, pictures, and bookmarks work inside a note. Comments need the review module and an EigenPal Pro License.

## Convert or delete a note

The packaged note controls convert a footnote to an endnote, or an endnote to a footnote. In edit mode, deleting a note removes its reference and body, then renumbers later notes.

In automation, `NoteItem.delete()` removes the note and its references. Run note deletion alone in its own sync, after all pending reads and writes.

Suggesting mode refuses direct note deletion. Delete the reference to propose note removal.

## Limits

- Automation does not create notes or format reference numbers.
- Notes inside headers and footers are not supported.
- Imported note revisions stay in the round-trip document.
- A continuation notice taller than the page reports `note-continuation-notice-height-cap`. The note text still continues.
- Numbering, placement, table rows, and continuation notices follow [DOCX fidelity](/docs/2.x/docx-fidelity#note-numbering).
