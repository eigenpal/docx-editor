The editor will expose two plugin systems. **EditorPlugin** will extend the browser editor with React UI: side panels, overlays painted over the pages, and scoped CSS. **CorePlugin** will extend the headless document engine with command handlers that edit a document without a browser. They share the same document model but run in different environments.

|              | **EditorPlugin** (planned)                         | **CorePlugin** (planned)                         |
| ------------ | -------------------------------------------------- | ------------------------------------------------ |
| Environment  | Browser (React)                                    | Node.js (headless)                               |
| Extends      | `<DocxEditor>` UI: panels, overlays                | `Document` edits via command handlers              |
| Registration | provider/hooks host surface (TBD)                  | `pluginRegistry.register(plugin)` (TBD)            |
| Entry point  | `@docx-editor.dev/react` composition layer         | `@docx-editor.dev/core` (TBD)                    |

These surfaces are **not shipped** on the current greenfield React and Vue adapters. The pages below describe the intended design from the archived plugin work; treat them as design reference until task 11.x lands paired acceptance.
