title: DOCX to PDF
description: Use the private Node PDF exporter with positioned text and native PDF comments.

---

`@docx-editor.dev/docx-to-pdf` is a private workspace package under the EigenPal Pro License. It is not available from the public npm registry.

The exporter uses Core's pagination, admitted fonts, and positioned glyphs. It does not run a browser or an office application. It runs on Node, because it resolves installed font files through `node:fs`. A browser application therefore converts by posting the document to a server.

The following example converts a document:

```ts
import { exportPdf } from '@docx-editor.dev/docx-to-pdf';

const result = await exportPdf(docxBytes, {
  displayMode: 'proposed',
  comments: true,
});
```

The default export shows proposed text, and preserves comments as native PDF annotations. To omit comments, set `comments: false`. To change the revision projection without changing the DOCX, select `displayMode: 'original'` or `'all-markup'`.

Strict export refuses requested content that the writer cannot reproduce. To receive available output with `result.diagnostics`, use `fidelityPolicy: 'best-effort'` explicitly.

Font substitution follows Core's separate font policy. `result.fontResolution` identifies the admitted faces. You can therefore see which face stood in for one the document asked for.

To open the local demo, run `bun run dev:pdf` in the repository. Edit the document on the left, then select **Generate PDF**. The preview appears on the right with a download link. An edit marks the preview stale, and the control becomes **Regenerate PDF**. Conversion therefore runs when you ask for it, rather than on every keystroke. The local demo converts in a Node worker and does not retain files. The hosted demo converts through a server function with the same limits, and accepts requests only from its own page.

The writer supports notes, textboxes, equation geometry, tab leaders, and multilingual font fallback. Unsupported content includes charts, rotated table text, and advanced drawing effects. For more information about supported content, resource limits, errors, and verification commands, see the [package documentation](https://github.com/eigenpal/docx-editor/tree/main/packages/docx-to-pdf).

The demo opens the same sample the editor uses.
