`@docx-editor.dev/docx-to-markdown` converts DOCX to Markdown with physical pages, headers, footers, comments, and tracked changes. It runs the layout engine in your Node.js process, with no office application, browser, or PDF step.

## Install the converter

Install the converter and its required Core peer. Use Node.js `^20.16.0 || >=22.3.0`.

```sh
npm install @docx-editor.dev/docx-to-markdown @docx-editor.dev/core
```

Install a Core version that satisfies the peer dependency range, and commit your lockfile. To package fonts and WebAssembly for deployment, see [Deploy with Next.js](/docs/2.x/export/markdown/integrations#deploy-with-nextjs).

## Convert a document

The following example converts a file and prints each page, then the continuous body:

```js
import { readFile } from 'node:fs/promises';
import { exportMarkdown } from '@docx-editor.dev/docx-to-markdown';

const result = await exportMarkdown(await readFile('contract.docx'), {
  displayMode: 'proposed',
});

for (const page of result.pages) {
  console.log(`Page ${page.number}`, page.markdown);
  console.log(page.headerMarkdown, page.footerMarkdown);
}

console.log(result.markdown); // Continuous document body.
console.log(result.warnings);
```

Export never accepts or rejects changes in the source file.

## Convert from Python

The [`docx-to-markdown` package on PyPI](https://pypi.org/project/docx-to-markdown/) wraps the same converter in a self-contained executable. It needs Python 3.11 or later and no Node.js installation.

```sh
pip install docx-to-markdown
```

The following example converts a file and prints the document Markdown:

```python
from docx_to_markdown import convert

result = convert("contract.docx")
print(result.markdown)
```

For pages, fonts, images, and batches, see the [Python package README](https://github.com/eigenpal/docx-editor/tree/main/python/docx-to-markdown#readme).

## Choose the output

| Need | Use |
| --- | --- |
| Continuous document text | `result.markdown` |
| Page references for citations | `result.pages`, with separate `headerMarkdown` and `footerMarkdown` |
| Comments and tracked changes | `result.reviewArtifacts` and each page's `comments` and `trackedChanges` |
| Image links and bytes | `images: true`; see [Images in Markdown exports](/docs/2.x/export/markdown/images) |
| Revision view | `displayMode`: `'all-markup'` (default) shows insertions and deletions; `'proposed'` hides deletions |

## Limits

- Page numbers describe one export snapshot. Fonts, document features, and `displayMode` change page breaks. See [Fonts and Markdown layout](/docs/2.x/export/markdown/fonts).
- Store the document version with citations, and inspect `warnings` for omitted content.
- Edge runtimes are unsupported.
- The converter, including review extraction, uses the Apache 2.0 license. Bundled fonts keep their own open-source licenses. For interactive review editing, see [Pro](/docs/2.x/pro).
- To add Markdown export to the editor File menu, see [Export Markdown and PDF](/docs/2.x/guides/export).
