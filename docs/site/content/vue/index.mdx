## Install and mount

Install the adapter, its engine peer, and Vue 3:

```bash
npm install @docx-editor.dev/vue @docx-editor.dev/core vue
```

Import the stylesheet once and render `<DocxEditor>` in a container with a height:

```vue
<script setup lang="ts">
import { DocxEditor } from '@docx-editor.dev/vue';
import '@docx-editor.dev/vue/styles.css';
</script>

<template>
  <div style="height: 100vh">
    <DocxEditor document="blank" />
  </div>
</template>
```

`<DocxEditor>` renders the title bar, menu, toolbar, navigation pane, hyperlink popover, context menu, and editable document.

## Limits

- The adapter requires Vue 3 and one shared copy of `@docx-editor.dev/core`.
- Load the stylesheet before you mount an editor, and give the editor's parent a measured height.
- On Nuxt, place the editor import and markup in a `.client.vue` component. See [Nuxt](/docs/2.x/frameworks/nuxt).
- Import components, composables, and engine helpers from the package root. The package has no `/ui`, `/composables`, or `/dialogs` subpaths. The stylesheet is the only separate export.
- Review comes from `@docx-editor.dev/pro/vue` under the EigenPal Pro License. PDF conversion runs on your Node.js server and also requires the EigenPal Pro License.
