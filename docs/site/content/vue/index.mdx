## Status

`@docx-editor.dev/vue` targets Vue 3 and ships in the same fixed version group as the React package. It shares the greenfield `DocxEditorProps` / seven-member `DocxEditorRef` contract where parity is enforced. React-first provider/hooks chrome (navigation pane, menu bar, context menu, hyperlink popover) is deferred; the engine commands those surfaces would drive are already shared.

## Install

```bash
npm install @docx-editor.dev/vue
```

Pulls in `@docx-editor.dev/core-contract` and `@docx-editor.dev/i18n`.

## Quickstart

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocxEditor } from '@docx-editor.dev/vue';

const doc = ref<ArrayBuffer | undefined>(undefined);
</script>

<template>
  <DocxEditor :document="doc" />
</template>
```

## Using with Nuxt

For Nuxt 3 and 4, install [`@docx-editor.dev/nuxt`](/docs/1.x/vue/nuxt), the official Nuxt module. It wraps this adapter and auto-imports an SSR-safe `<DocxEditor>`, so there's no `<ClientOnly>` wrapper to write:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@docx-editor.dev/nuxt'],
});
```

See [Nuxt](/docs/1.x/vue/nuxt) for the module options and what to import from the adapter directly.

## Subpaths

- `@docx-editor.dev/vue`: `<DocxEditor>`, `DocxEditorProps`, `DocxEditorRef`, `EditorMode`, `DocxEditorToolbar`, rulers, title bar, and shared engine helpers (`toolbarCommandState`, `commandForSlot`, …)

Every export is in the [Vue API reference](/docs/1.x/api/vue).

## Parity with React

`scripts/parity/parity.contract.json` lists every public prop and ref member shipped under either adapter, grouped as paired, deferred-in-Vue, or adapter-specific. CI parses both packages' API snapshots and fails when the contract changes without an update.

## Agent integration

Same toolkit, Vue subpath:

```ts
import { useAgentBridge } from '@docx-editor.dev/agents/vue';

const { executeToolCall, toolSchemas } = useAgentBridge({
  editorRef,
  author: 'Assistant',
});
```

The live bridge is pending rebuild over the greenfield engine. Render agent UI components next to the editor (see [Vue examples](/docs/1.x/vue/examples)).
