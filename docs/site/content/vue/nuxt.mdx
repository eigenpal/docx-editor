`@docx-editor.dev/nuxt` is the official Nuxt module. It wraps [`@docx-editor.dev/vue`](/docs/1.x/vue) and registers an SSR-safe `<DocxEditor>` as an auto-imported component, so a Nuxt app needs no manual import and no `<ClientOnly>` wrapper. It supports Nuxt 3 and Nuxt 4.

For a step-by-step walkthrough with loading, saving, tracked changes, and collaboration, see the [Nuxt DOCX editor guide](/blog/nuxt-docx-editor).

## Install

```bash
npm install @docx-editor.dev/nuxt
```

Pulls in `@docx-editor.dev/vue`, and transitively `@docx-editor.dev/core-contract` and `@docx-editor.dev/i18n`.

## Register the module

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@docx-editor.dev/nuxt'],
});
```

That is the whole setup. The module registers `<DocxEditor>` as a client-only component.

## Use the component

```vue
<script setup lang="ts">
import { ref } from 'vue';

const buf = ref<ArrayBuffer | null>(null);
</script>

<template>
  <DocxEditor :document="buf ? new Uint8Array(buf) : undefined" />
</template>
```

No import, no `<ClientOnly>`. `<DocxEditor>` is the same root component exported by [`@docx-editor.dev/vue`](/docs/1.x/vue). The full prop list is on [Vue props](/docs/1.x/vue/props).

## Load a document

Pass DOCX bytes through the `document` prop:

```vue
<script setup lang="ts">
import { ref } from 'vue';

const doc = ref<Uint8Array>();

async function load(e: Event) {
  const file = (e.target as HTMLInputElement).files?.[0];
  if (!file) return;
  doc.value = new Uint8Array(await file.arrayBuffer());
}
</script>

<template>
  <input type="file" accept=".docx" @change="load" />
  <DocxEditor v-if="doc" :document="doc" />
</template>
```

To save, call `save()` on the component's `DocxEditorRef`; it resolves to an `ArrayBuffer` of OOXML bytes (`null` if no document is loaded), the same format the editor reads. The [Nuxt DOCX editor guide](/blog/nuxt-docx-editor) covers loading from a URL, saving to a download or a Nitro route, tracked changes, and collaboration.

## Options

```ts
export default defineNuxtConfig({
  modules: ['@docx-editor.dev/nuxt'],
  docxEditor: {
    prefix: 'Ep',
    injectStyles: true,
  },
});
```

| Option         | Type      | Default | Description                                                                      |
| -------------- | --------- | ------- | -------------------------------------------------------------------------------- |
| `prefix`       | `string`  | `''`    | Component name prefix. `Ep` registers `<EpDocxEditor>`.                          |
| `injectStyles` | `boolean` | `true`  | Controls whether the module wires the editor stylesheet into `nuxt.options.css`. |

## What the module re-exports

The module gives you the auto-imported `<DocxEditor>` component. When you need the rest of the Vue adapter surface, import it from `@docx-editor.dev/vue` directly:

- the `DocxEditorProps` and `DocxEditorRef` types
- root-level helpers like `DocxEditorShell`, `DocxEditorToolbar`, `DocxEditorSidebar`, `HorizontalRuler`, and `PageIndicator`

If you use those exports, add the adapter to your own `dependencies` so the import is explicit:

```bash
npm install @docx-editor.dev/vue
```
