The Vue root component is intentionally small. The full generated reference is at [/docs/1.x/api/vue](/docs/1.x/api/vue); this page summarizes the current root prop shape and exposed handle.

## Binding the root props

Camel-case in TS, kebab-case in the template. Bind with `:` for non-string values:

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocxEditor, type EditorMode } from '@docx-editor.dev/vue';

const doc = ref<Uint8Array>();
const mode = ref<EditorMode>('edit');
</script>

<template>
  <DocxEditor :document="doc" :mode="mode" author="Jess Lin" />
</template>
```

## Current props

| Prop          | Type                                             | Description                                      |
| ------------- | ------------------------------------------------ | ------------------------------------------------ |
| `document`    | `DocumentSource`                                 | DOCX bytes or an existing `DocumentHandle`.      |
| `fonts`       | `FontConfiguration \| FontConfigurationFragment` | Font bytes used for measurement and pagination.  |
| `mode`        | `'edit' \| 'view'`                               | Mount-time editing mode.                         |
| `zoom`        | `number`                                         | Mount-time zoom value.                           |
| `locale`      | `string`                                         | Locale passed to the underlying editor instance. |
| `author`      | `string`                                         | Ambient author for authored commands.            |
| `onFontError` | `(error: EditorFontError) => void`               | Reports typed font-resolution failures.          |

## Template ref

```vue
<script setup lang="ts">
import { useTemplateRef } from 'vue';
import { DocxEditor, type DocxEditorRef } from '@docx-editor.dev/vue';

const editor = useTemplateRef<DocxEditorRef>('editor');

async function save() {
  const buf = await editor.value?.save(); // Promise<ArrayBuffer | null>
  if (buf) await fetch('/api/documents/1', { method: 'PUT', body: buf });
}
</script>

<template>
  <button @click="save">Save</button>
  <DocxEditor ref="editor" :document="doc" />
</template>
```

`DocxEditorRef` matches the React handle one-to-one: `load`, `save`, `getDocumentHandle`, `getEditor`, `focus`, `exec`, and `snapshot`.

## Common handle methods

| Method                    | Returns                        | What it does                                     |
| ------------------------- | ------------------------------ | ------------------------------------------------ |
| `load(document)`          | `void`                         | Load DOCX bytes or an existing `DocumentHandle`. |
| `save()`                  | `Promise<ArrayBuffer \| null>` | Serialize the current document to DOCX bytes.    |
| `getDocumentHandle()`     | `DocumentHandle \| null`       | Current document handle + revision.              |
| `getEditor()`             | `Editor \| null`               | Reach the full editor facade.                    |
| `exec(command, options?)` | `ExecResult`                   | Run a typed command against the current scope.   |
| `snapshot(options?)`      | `EditorSnapshot`               | Read the current facade snapshot.                |
| `focus()`                 | `void`                         | Focus the mounted editor surface.                |

## Example with custom fonts

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocxEditor, loadFonts } from '@docx-editor.dev/vue';

const doc = ref<Uint8Array>();
const fonts = loadFonts({
  defaultFont: { family: 'Inter', sizeHalfPoints: 22 },
  sources: [{ family: 'Inter', src: '/fonts/Inter-Regular.woff2' }],
});
</script>

<template>
  <DocxEditor :document="doc" :fonts="fonts" />
</template>
```
