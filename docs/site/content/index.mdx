`docx-editor` is a WYSIWYG DOCX editor for React and Vue 3. It parses OOXML, renders paginated pages, and saves DOCX in the browser. Browser editing needs no upload or conversion service.

## Install an editor

Install an adapter and the engine:

<FrameworkTabs>
<Framework value="react">

```bash
npm install @docx-editor.dev/react @docx-editor.dev/core
```

</Framework>
<Framework value="vue">

```bash
npm install @docx-editor.dev/vue @docx-editor.dev/core
```

</Framework>
</FrameworkTabs>

Render the editor in a container with a height:

<FrameworkTabs>
<Framework value="react">

```tsx
import { DocxEditor } from '@docx-editor.dev/react';
import '@docx-editor.dev/core/styles/editor.css';

export default function App() {
  return (
    <div style={{ height: '100vh' }}>
      <DocxEditor document="blank" />
    </div>
  );
}
```

</Framework>
<Framework value="vue">

```vue
<script setup lang="ts">
import { DocxEditor } from '@docx-editor.dev/vue';
import '@docx-editor.dev/vue/styles.css';
</script>

<template>
  <div style="height: 100vh">
    <DocxEditor document="blank" />
  </div>
</template>
```

</Framework>
</FrameworkTabs>

To open and save files, continue with the [quickstart](/docs/2.x/quickstart). In server-rendered frameworks, mount the editor on the client only. See [Installation](/docs/2.x/installation).

## Choose an integration

| Task | Packages | Guide |
| --- | --- | --- |
| Edit DOCX in a React or Vue app | `@docx-editor.dev/react` or `@docx-editor.dev/vue`, plus `@docx-editor.dev/core` | [Quickstart](/docs/2.x/quickstart) |
| Show tracked changes and comments | Add `@docx-editor.dev/pro` | [Pro package](/docs/2.x/pro) |
| Edit from a server, worker, or agent | `@docx-editor.dev/editor-api` | [Editing API](/docs/2.x/editor-api) |
| Automate an open browser editor | `@docx-editor.dev/editor-api/browser` | [Editing API](/docs/2.x/editor-api) |
| Convert DOCX to Markdown | `@docx-editor.dev/docx-to-markdown` | [Markdown export](/docs/2.x/export/markdown) |
| Convert DOCX to PDF on Node.js | `@docx-editor.dev/docx-to-pdf` | [PDF export](/docs/2.x/export/pdf) |

The editing API follows a documented subset of the Office.js object model. It does not claim full Office.js compatibility.

## Which API for which job

Use the React or Vue adapter hooks, the review hooks, and `DocxEditorReview` from `@docx-editor.dev/pro/react` or `@docx-editor.dev/pro/vue` to build browser review controls. Use the editing API in `@docx-editor.dev/editor-api` for document automation. It follows the Office.js object model and runs in browser and server hosts.

| Task | Browser controls (React or Vue) | Document automation |
| --- | --- | --- |
| [Comment on found text](/docs/2.x/recipes/comment-on-found-text) | `editor.findMatches`, `editor.selectMatch`, then `useReview().comment` | `body.search`, then `Range.insertComment` |
| [Reply to a thread](/docs/2.x/pro/comments) | `useReview().reply(item, text)` | `Comment.reply(text)` |
| [Record a tracked replacement](/docs/2.x/recipes/tracked-replacement) | Suggesting mode, then `editor.exec({ type: 'replaceMatch', match, text })` | `document.changeTrackingMode = 'TrackMineOnly'`, then `Range.insertText(text, 'Replace')` |
| [Propose an AI rewrite as tracked changes](/docs/2.x/recipes/propose-rewrite) | `prepareRewrite` through `DocxEditor.createBrowser` | `prepareRewrite` from `@docx-editor.dev/editor-api/agent` |
| [Accept or reject a change](/docs/2.x/recipes/accept-reject-without-scrolling) | `useReview().accept(item)` or `useReview().reject(item)` | `Revision.accept()` or `Revision.reject()` |
| [Open a change without scrolling](/docs/2.x/recipes/accept-reject-without-scrolling) | `useReview().setActive(key, { reveal: false })` | Not applicable: no viewport |
| [Highlight ranges](/docs/2.x/recipes/highlight-ranges) | `useHighlights(name, source, options)` | Not applicable |
| [Custom review rail cards](/docs/2.x/recipes/custom-review-cards) | `DocxEditorReview` with `preset` set to `false`, `useStackedReviewPositions`, and `useReviewRailMetrics` | Not applicable |
| Comment-on-selection button | `DocxEditorReview.AddComment` as a direct child of `DocxEditorReview`, or `useEditorCommand('review.addComment')` | Not applicable |
| [Page setup and paragraph dialogs](/docs/2.x/customization/dialogs) | `DocxEditor.PageSetupDialog` or `DocxEditor.ParagraphDialog` | `Section.pageSetup`, and `Paragraph` properties such as `alignment` |

For worked examples, see [Task recipes](/docs/2.x/recipes).
