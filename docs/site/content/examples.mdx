## Run a repository starter

Clone the repository, then install dependencies and build the packages from the root:

```bash
git clone https://github.com/eigenpal/docx-editor.git
cd docx-editor
bun install
bun run build:packages
```

Run the `bun run dev:*` command from the starter README. The Vite with React and Vite with Vue starters alias package source and do not need `build:packages`.

## Use published packages

- Web starters use `workspace:*` dependencies for `@docx-editor.dev/*` packages, not published npm versions.
- To use published packages, replace the `workspace:*` versions in the starter's `package.json`.
- The Vue adapter is published to npm. The Nuxt module is a private workspace package.
