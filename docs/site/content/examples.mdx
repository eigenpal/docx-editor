## Runnable starters

You can find each starter in the repository's
[`examples/` directory](https://github.com/eigenpal/docx-editor/tree/main/examples).
The web starters use `workspace:*` dependencies for `@docx-editor.dev/*` packages.
They do not use the published npm packages.

Follow these steps to run a web starter:

1. Clone the repository.
2. Run this command from the repository root to install dependencies:

   ```bash
   bun install
   ```

3. Build the packages if the starter README requires a build:

   ```bash
   bun run build:packages
   ```

   The Vite with React and Vite with Vue starters alias package source.
   These two starters do not need this build.

4. Run the `bun run dev:*` command from the starter README.

To use published packages, replace the `workspace:*` versions in the starter's `package.json`.
