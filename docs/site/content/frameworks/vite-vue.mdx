## Install

```bash
npm install @docx-editor.dev/vue @docx-editor.dev/core
```

## Mount the editor

Vite renders on the client, so you do not need a server-rendering boundary. Import the stylesheet in the entry and mount the app:

```ts
// src/main.ts
import { createApp } from 'vue';
import '@docx-editor.dev/vue/styles.css';
import App from './App.vue';

createApp(App).mount('#app');
```

Render the editor in a container with a height:

```vue
<!-- src/App.vue -->
<script setup lang="ts">
import { DocxEditor } from '@docx-editor.dev/vue';
</script>

<template>
  <div style="height: 100vh">
    <DocxEditor document="blank" />
  </div>
</template>
```

To open and download files, use the Vue component from the [quickstart](/docs/2.x/quickstart).

## Limits

- Mount the app on the element from your `index.html`. The standard Vite Vue template uses `#app`.
- This setup assumes a client-rendered Vite app. For Nuxt, see [Nuxt](/docs/2.x/frameworks/nuxt).
- The editor fills its parent, so the parent needs a measured height.

## Run the example

The [`examples/vue`](https://github.com/eigenpal/docx-editor/tree/main/examples/vue) starter aliases package source, so it needs no package build. After you clone the repository and run `bun install`, run:

```bash
bun run dev:vue   # http://localhost:5174
```
