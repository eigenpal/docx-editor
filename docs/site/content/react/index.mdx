## Install and mount

Install the adapter and its engine peer:

```bash
npm install @docx-editor.dev/react @docx-editor.dev/core
```

Import the stylesheet once and render `<DocxEditor>` in a container with a height:

```tsx
import { DocxEditor } from '@docx-editor.dev/react';
import '@docx-editor.dev/core/styles/editor.css';

export default function App() {
  return (
    <div style={{ height: '100vh' }}>
      <DocxEditor document="blank" />
    </div>
  );
}
```

`<DocxEditor>` renders the title bar, menu, toolbar, navigation pane, hyperlink popover, context menu, and editable document.

## Choose an API

| Task | API | Guide |
| --- | --- | --- |
| Configure the packaged editor | `<DocxEditor>` props and `DocxEditorRef` | [React props](/docs/2.x/react/props) |

| Build custom controls | `useDocxEditor`, `useEditorState`, `useEditorCommand`, `useEditorEvent` | [React hooks](/docs/2.x/react/hooks) |
| Automate the open document | `@docx-editor.dev/editor-api/browser` | [React examples](/docs/2.x/react/examples) |
| Export Markdown or PDF, and print | `menu.exporters` | [Export](/docs/2.x/guides/export), [Print](/docs/2.x/guides/print) |
| Show tracked changes and comments | `@docx-editor.dev/pro/react` | [Pro package](/docs/2.x/pro) |

## Limits

- The adapter requires one shared copy of `@docx-editor.dev/core`.
- Import the stylesheet once, and give the editor's parent a measured height.
- In the Next.js App Router, load the editor with `dynamic()` and `ssr: false` from a client component. The `"use client"` directive alone does not disable server rendering. See [Next.js](/docs/2.x/frameworks/nextjs).
- Import components, hooks, and engine helpers from the package root. The package has no `/ui`, `/hooks`, or `/dialogs` subpaths.
- Review comes from `@docx-editor.dev/pro` under the EigenPal Pro License. PDF conversion runs on your Node.js server and also requires the EigenPal Pro License.
