## Install

```bash
npm install @docx-editor.dev/react
```

Pulls in `@docx-editor.dev/core-contract` and `@docx-editor.dev/i18n`. Add `@docx-editor.dev/agents` if you need the agent toolkit UI.

## Quickstart

```tsx
import { DocxEditor } from '@docx-editor.dev/react';

export default function App() {
  return <DocxEditor document={docxBytes} />;
}
```

On Next.js App Router, render this inside a `"use client"` component. The editor mounts a painted surface in the browser; there is nothing to SSR. The [Next.js DOCX editor guide](/blog/nextjs-docx-editor) walks through file uploads, saving to an API route, and the common errors.

## Subpaths

- `@docx-editor.dev/react`: `<DocxEditor>`, `DocxEditorRef`, `DocxEditorProps`, `EditorMode`, composition primitives (`DocxEditor.Root` / `.Viewport` / `.Content`), hooks, and chrome compounds (`DocxEditor.Toolbar`, `.Menu`, `.Navigation`, …)

## Loading a document

Pass a `document` prop: DOCX bytes (`ArrayBuffer` / `Uint8Array`) or an existing `DocumentHandle` from a prior save. Omit it to mount an empty document. Full patterns (URL, file input, saving) are in [Loading and saving](/docs/1.x/guides/loading-and-saving).

## Ref methods

`DocxEditorRef` is a seven-member imperative handle shared with Vue (enforced by `bun run check:parity-contract`):

```tsx
import { useRef } from 'react';
import { DocxEditor, type DocxEditorRef } from '@docx-editor.dev/react';

const editorRef = useRef<DocxEditorRef>(null);

await editorRef.current?.save();
const editor = editorRef.current?.getEditor();
editorRef.current?.exec({ kind: 'text.bold' });
```

Advanced reads (formatting state, outline, page setup) go through `getEditor()` and `snapshot()`. Every method is safe before mount — reads return honest empty answers, mutations no-op.

## Toolbar

The default chrome renders `DocxEditor.Toolbar` from the root export. Compose your own from the same primitives:

```tsx
import { DocxEditor, DocxEditorToolbar, Toolbar, ToolbarButton } from '@docx-editor.dev/react';
```

See [Toolbar customization](/docs/1.x/guides/toolbar) for slot overrides, menu bar wiring, and title-bar slots.

## Agent integration

Wire AI tools to a live editor with `@docx-editor.dev/agents/react`:

```tsx
import { DocxEditor } from '@docx-editor.dev/react';
import { useDocxAgentTools } from '@docx-editor.dev/agents/react';
```

The live bridge is pending rebuild over the greenfield engine; static review via `DocxReviewer` remains available from `@docx-editor.dev/agents`. Full client + server wiring is on [Agents → Live editor](/docs/1.x/agents/live-editor).
