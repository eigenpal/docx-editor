# Changes in this fork

This repository is a modified copy of [docx-editor](https://github.com/eigenpal/docx-editor) by Eigenpal, Inc., licensed under the Apache License 2.0 ([LICENSE](LICENSE)). It was forked from upstream commit `e2cbc55`. Eigenpal, Inc.'s copyright and attribution notices are kept as they were.

Changes were made in 2026 for Grant Workbench. Every changed file that takes comments carries a line saying so at the top. The files that can't hold comments (JSON, Markdown, config) are listed below.

## What changed

1. **Removed** everything not licensed under Apache-2.0: `packages/pro`, `packages/editor-api`, `packages/docx-to-pdf` and `packages/telemetry` (EigenPal Pro Evaluation License 1.0). Also removed: the upstream examples (except our `examples/free-review`), the `e2e/` suite, `benchmarks/`, `api/`, `docs/site/`, the upstream release, collaboration and CI tooling (`.github/workflows`, `.collaboration`, `openspec`, related `scripts/`), and docs that described the Pro packages.
2. **Reworded** comments, docs and user-facing messages in the Apache packages that told users to install or import a Pro package. The PDF export messages in `packages/i18n` now say "PDF converter" instead of naming `@docx-editor.dev/docx-to-pdf`. The core's review-module refusal messages no longer name `@docx-editor.dev/pro`.
3. **Tests**: removed tests that exercised Pro features; replaced Pro review-module imports with the core's own test stub; moved the shared test documents from `e2e/fixtures/` to `fixtures/` and updated their paths; copied an OFL-licensed Noto Sans Devanagari subset into `packages/core/src/export/__tests__/fixtures/`.
4. **Tooling**: root `package.json` workspaces and scripts, `tsconfig.json`, `.oxlintrc.json`, `tailwind.config.js`, ignore files, `.changeset/config.json` and the pre-commit gates now cover only what remains.
5. **Added** (our own work, Apache-2.0): `extensions/review` (`@gw/docx-review`, a review module and panel), `examples/free-review`, this file, and the `NOTICE` files.

No functional change was made to the engine (`packages/core`), the React adapter (`packages/react`), the fonts or the i18n strings beyond the wording above.
