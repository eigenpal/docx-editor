The font size box is now a combobox: click it for the preset list, or type any size including one off the ladder. Wire the line spacing control, which applies Word's multiples and the add/remove space before/after paragraph commands. Adds the `setLineSpacing` and `setParagraphSpacing` editor commands, and reports line spacing and paragraph space on the selection formatting.
