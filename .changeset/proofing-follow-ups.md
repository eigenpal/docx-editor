Proofing tools can check only the paragraphs an edit touched with the `paragraphsChange` event, expose spelling and grammar marks to screen readers with the highlight `kind` option, move between marks with the `navigateHighlight` command, and add critiques through the Office.js annotation members of the editing API. A context menu opened from the keyboard no longer closes at once after a background layout pass.
