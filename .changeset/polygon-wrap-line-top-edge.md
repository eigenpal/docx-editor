A line that starts just above an object with tight or through wrapping, and reaches into it, wraps beside the object. Text beside a tight or through wrap keeps clear of the widest part of the wrap outline on each line, and a line that starts at the bottom edge of such an object wraps beside it. A wrapping object near the page bottom moves its line to the next page when lifting the object would overlap that line.
