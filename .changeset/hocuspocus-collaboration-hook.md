Add `useHocuspocusCollaboration` (React and Vue) and `createHocuspocusCollaboration` on new `hocuspocus` subpaths, so a Hocuspocus server room works the same way a WebRTC room does. The `token` option accepts a renewal callback, and a rejected token fails fast instead of waiting out the sync timeout.
